    Operators

    Both operands of an arithmetic, comparison, or bitwise operator must have the same type; qiq never converts between types implicitly, so 1 + 1.5 is an error. Use to_double(1) + 1.5 instead.

    Arithmetic operators

    OperatorNameExample
    a + bAddition (or concatenation of strings and chars)7 + 3 is 10
    a - bSubtraction7 - 10 is -3
    a * bMultiplication6 * 7 is 42
    a / bDivision7 / 2 is 3; 7.0 / 2.0 is 3.5
    a % bRemainder7 % 3 is 1; 7.5 % 2.0 is 1.5
    a ** bPower2 ** 10 is 1024
    -aNegation-(3 + 4) is -7
    • Int arithmetic is 64-bit and wraps on overflow.
    • Int / truncates toward zero, and % takes the sign of the left operand: -7 / 2 is -3 and -7 % 3 is -1.
    • Int / or % by zero throws DivisionByZeroException, and an int raised to a negative power throws ArithmeticException. Double arithmetic follows IEEE 754, so 1.0 / 0.0 is inf.
    print(7 / 2, -7 % 3, 2 ** 10, 7.0 / 2.0);
print(2 + 3 * 4, (2 + 3) * 4, -2 ** 2);
int zero = 0;
try {
    print(1 / zero);
} catch (DivisionByZeroException e) {
    print("caught:", e->getMessage());
}
    Output
    3 -1 1024 3.5
14 20 -4
caught: division by zero

    Comparison operators

    OperatorTrue whenWorks on
    a == b, a != bEqual, not equalint, double, bool, byte, string, char, null
    a < b, a > b, a <= b, a >= bOrderingint, double, byte (unsigned), string, char

    Comparisons produce a bool and can be used anywhere, not only in if. Strings and chars compare by content; ordering uses UTF-8 byte order, which is Unicode code-point order, not locale-aware alphabetical order. Arrays, maps, and objects can't be compared with each other. Comparisons can't be chained: write 0 < n && n < 5, not 0 < n < 5.

    Comparing with null

    Strings, chars, arrays, maps, and objects can be compared with null using == and !=, to test whether they have a value. A null string is equal only to null, so comparing one with a string is false rather than an error; ordering a null string with < or > throws RuntimeException.

    string[] names = new string[2];
names[1] = "Ada";
print(names[0] == null, names[1] != null, names[0] == "Ada");
int[] scores = null;
if (scores == null) {
    scores = [90, 85];
}
print(scores);
    Output
    1 1 0
[90, 85]

    The null coalescing operator

    left ?? right gives left, or right when left is missing: a map key that isn't there, an array index out of range (or a null array), or a null value. right is only evaluated when it's needed. It's PHP's ??, and Python's dict.get(key, default).

    map[string, string] settings = {"theme" => "dark"};
string[] args = ["run"];
string name = null;

print(settings["theme"] ?? "light", settings["font"] ?? "mono");
print(args[0] ?? "help", args[3] ?? "none");
print(name ?? "anonymous");
print(settings["lang"] ?? settings["locale"] ?? "en");
    Output
    dark mono
run none
anonymous
en
    • The left side must be a map or array element, or a string, char, array, map, or object that can be null. The right side must have the same type, and can be null for those types.
    • ?? has the lowest precedence of all operators and groups to the right, so a ?? b ?? c tries a, then b, then c.
    • Unlike PHP, a missing property or a null object earlier in a chain, as in user->address->city ?? "", isn't covered: only the last step is checked.

    Logical operators

    OperatorResult
    a && btrue if both are true; b is evaluated only if a is true
    a || btrue if either is true; b is evaluated only if a is false
    !atrue if a is false

    The operands must be bool.

    int age = 30;
bool adult = age >= 18;
print(adult, age > 65 || age < 18, !adult);
print(adult && age != 31);
    Output
    1 0 0
1

    Bitwise operators

    OperatorNameExample
    a & bAnd12 & 10 is 8
    a | bOr12 | 3 is 15
    a ^ bExclusive or12 ^ 10 is 6
    ~aComplement~12 is -13
    a << bShift left1 << 4 is 16
    a >> bShift right, keeping the sign-16 >> 2 is -4

    Bitwise operators take int operands. Shifting by a negative amount throws ArithmeticException; shifting by 64 or more gives 0, or -1 when shifting a negative number right.

    String concatenation

    + joins strings and chars in any mix, producing a string: "a" + 'b' is "ab". To include a number, convert it first: "count: " + to_string(n).

    Precedence

    From lowest to highest; operators on the same row have the same precedence and, except for **, group left to right. Parentheses override precedence.

    OperatorsNotes
    ||
    &&
    == !=
    < > <= >=Can't be chained
    |
    ^
    &
    << >>
    + -
    * / %
    unary - ~ !
    **Groups right to left: 2 ** 3 ** 2 is 2 ** 9
    Note: Unlike PHP and C, bitwise operators bind tighter than comparisons, so x & 1 == 0 means (x & 1) == 0. And as in PHP, ** binds tighter than unary minus, so -2 ** 2 is -4.
