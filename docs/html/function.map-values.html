    map_values

    map_values — The values of a map, as an array

    Description

    map_values(map[K, V] map): V[]

    Returns a new array of the map's values, in the order their keys were added. The array refers to the same arrays, maps, and objects as the map; it doesn't copy them.

    Parameters

    map
    The map.

    Return values

    The values.

    Errors/Exceptions

    • RuntimeException if the map is null.

    Examples

    Example #1 Summing values

    map[string, int] stock = {"pears" => 2, "apples" => 5};
int total = 0;
foreach (map_values(stock) as count) {
    total = total + count;
}
print(map_values(stock), total);
    Output
    [2, 5] 7
