    Exception classes

    These classes are available in every file without an import, wherever they're defined. The runtime and the standard library throw them, and your own exceptions extend them. See Exceptions for throw, try, catch, and finally.

    Hierarchy

    Exception
├── RuntimeException
│   ├── IOException
│   │   ├── FileNotFoundException
│   │   ├── PermissionDeniedException
│   │   └── NetworkException
│   ├── KeyNotFoundException
│   ├── OutOfRangeException
│   └── InvalidUtf8Exception
├── ArithmeticException
│   └── DivisionByZeroException
├── InvalidArgumentException
├── JsonException
└── HttpException

    The Exception class

    class Exception {
        protected string message;
        protected int code;
        function __construct(string message = "", int code = 0)
        function getMessage(): string
        function getCode(): int
    }

    Every subclass inherits the constructor and both methods. A subclass that declares no constructor uses this one, so class ConfigException extends Exception {} is enough to define a new exception.

    When each is thrown

    ClassThrown when
    RuntimeExceptionAn error that can only be detected while the program runs, such as using a null array or string, or new static on an abstract class.
    IOExceptionReading or writing a file failed for a reason other than the two below, such as reading a directory.
    FileNotFoundExceptionA path given to a file function doesn't exist.
    PermissionDeniedExceptionThe operating system denied access to a file.
    KeyNotFoundExceptionA map lookup used a key that isn't in the map.
    OutOfRangeExceptionAn array index is below 0 or not less than the array's length.
    InvalidUtf8ExceptionBytes or file contents that should be text aren't valid UTF-8.
    ArithmeticExceptionAn int raised to a negative power, a negative shift amount, or a double that can't be converted to an int.
    DivisionByZeroExceptionInt / or % with a zero right-hand side.
    InvalidArgumentExceptionA standard library function was given an argument it can't accept, such as a negative str_repeat count.
    JsonExceptionjson_decode was given text that isn't JSON or doesn't match the type it decodes into, or json_encode was given a value JSON can't represent.
    NetworkExceptionA network connection failed: the host couldn't be found, refused the connection, timed out, closed it early, or failed the TLS certificate check. A subclass of IOException.
    HttpExceptionResponse::raiseForStatus() found a 4xx or 5xx status (the status is the exception's code), or a request was redirected more than 10 times.

    Example

    class ConfigException extends Exception {}

try {
    throw new ConfigException("port is empty", 7);
} catch (Exception e) {
    print(e->getMessage(), e->getCode());
}

map[string, int] ages = {"ada" => 36};
try {
    print(ages["bob"]);
} catch (KeyNotFoundException e) {
    print("KeyNotFoundException:", e->getMessage());
}
    Output
    port is empty 7
KeyNotFoundException: map key not found
