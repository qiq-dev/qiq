    to_string

    to_string — Convert a value to a string

    Description

    to_string(int|double|byte|bool|char value): string

    Converts value to text: ints and bytes in decimal, doubles formatted like print (%g), booleans as true or false, and a char as a one-character string.

    Parameters

    value
    The value to convert.

    Return values

    The text.

    Examples

    Example #1 Building a message

    print("count: " + to_string(42) + ", ratio: " + to_string(0.5) + ", ok: " + to_string(true));
    Output
    count: 42, ratio: 0.5, ok: true

    Notes

    Note: to_string(true) is "true", while print(true) prints 1.
