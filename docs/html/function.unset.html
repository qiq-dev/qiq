    unset

    unset — Remove an entry from a map

    Description

    unset(map[key] entry): void

    Removes the entry for the key, if there is one; removing a key that isn't there does nothing, as in PHP. The other entries keep their order. For arrays, use array_splice, which moves the later elements down.

    Parameters

    entry
    The entry to remove, written as an index: unset(ages["ada"]).

    Return values

    Nothing.

    Errors/Exceptions

    • RuntimeException if the map is null. Using unset on an array element, or on anything other than a map entry, is a compile error.

    Examples

    Example #1 Removing entries

    map[string, int] ages = {"ada" => 36, "lin" => 29, "bob" => 50};
unset(ages["lin"]);
unset(ages["nobody"]);
print(ages, len(ages));
    Output
    {"ada" => 36, "bob" => 50} 2

    Example #2 While iterating

    map[string, int] scores = {"ada" => 90, "lin" => 40, "bob" => 75};
foreach (scores as name => score) {
    if (score < 50) {
        unset(scores[name]);
    }
}
print(scores);
    Output
    {"ada" => 90, "bob" => 75}
