    http_serve

    http_serve — Run an HTTP server

    Description

    http_serve(string address, function(Request, ResponseWriter): void handler, int workers = 0, bool trustProxy = false): void

    Import it with import http_serve from "std/http/server";

    Listens on the address, starts the workers, and serves requests until the program gets SIGINT (Ctrl-C) or SIGTERM. Each worker serves one connection at a time; see How the server works.

    Parameters

    address
    Where to listen: ":8080" for every network interface (IPv4 and IPv6), "127.0.0.1:8080" for this machine only, "[::1]:8080" for an IPv6 address, or "unix:/run/app.sock" for a Unix socket file, to sit behind a proxy such as nginx.
    handler
    Called for each request; usually router->handler().
    workers
    The number of worker processes; 0 means one per CPU. With 1, the server runs in this process without forking.
    trustProxy
    Whether the server is behind a proxy such as nginx. If so, Request::remoteAddress is the client address the proxy forwarded (the last entry of X-Forwarded-For, or X-Real-IP), and Request::scheme comes from X-Forwarded-Proto. Only set it when clients can't reach the server except through the proxy, because anyone else could send those headers.

    Return values

    Returns in the first process once the workers have finished their requests and stopped; worker processes exit without returning.

    Errors/Exceptions

    • NetworkException if the address can't be used, for example because another program is listening on the port (could not listen on :8080: Address in use) or on the socket file.
    • InvalidArgumentException for an address without a port.

    Examples

    Example #1 Hello, world

    import http_serve, Request, ResponseWriter from "std/http/server";

http_serve(":8080", fn(Request r, ResponseWriter w) => w->write("Hello, world!\n"));

    Example #2 Behind nginx, on a Unix socket

    import http_log, http_serve from "std/http/server";

http_serve("unix:/run/app/app.sock", http_log(router->handler()), trustProxy: true);

    Example #3 Two workers on localhost

    import date from "std/time";
import http_log, http_serve, Request, ResponseWriter, Router from "std/http/server";

Router router = new Router();
router->handle("GET /time", fn(Request r, ResponseWriter w) => w->write(date("H:i:s") + "\n"));
http_serve("127.0.0.1:3000", http_log(router->handler()), workers: 2);
print("stopped");
