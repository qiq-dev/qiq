    Installing and running

    Requirements

    To…You need
    Compile and run qiq programsOnly the qiq binary. It contains everything it needs: LLVM for code generation, the qiq runtime, musl libc, and a linker. It runs on x86-64 Linux.
    Download packagesgit, used by qiq get, and by builds that need a module that isn't downloaded yet.
    Run a compiled programNothing. Executables are statically linked, so they run on any x86-64 Linux machine.
    Build qiq itselfSee the README in the qiq repository.

    Your first program

    Save this as hello.qiq:

    string name = "world";
print("Hello, " + name + "!");
    Output
    Hello, world!

    Then run it:

    qiq run hello.qiq          # compile and run, like `php hello.php` or `go run`

    Commands

    qiq run hello.qiq [arguments...]    # compile to a temporary executable and run it
qiq build hello.qiq                 # write the executable ./hello
qiq build hello.qiq -o app          # choose the output name
qiq build hello.qiq --emit-llvm     # also write hello.ll, the generated LLVM IR
qiq serve public --port 8080        # serve a directory over HTTP, like `php -S`
qiq mod init github.com/you/app     # make this directory a module (see Packages)
qiq get github.com/ada/web          # add a module (needs git)
qiq mod tidy                        # require exactly the modules that are imported
qiq help                            # show a summary
qiq version                         # show the version
    • qiq run exits with the program's exit status: 0 normally, and 1 when an exception is never caught.
    • Both commands optimize the program (like -O2). A small program compiles in about a fifth of a second.
    • Compile errors name the file and, for syntax errors, the line and column: hello.qiq:3:12: expected ';' after declaration.
    • qiq serve [directory] [--host host] [--port port] [--workers n] serves a directory's files (the current one by default) at http://127.0.0.1:8000/; see HTTP server.
    • The older form qiq hello.qiq -o hello still works and means qiq build.

    How a program is built

    Everything happens inside the qiq process: the compiler turns qiq source into LLVM IR; LLVM optimizes it together with the qiq runtime and emits machine code; and a built-in linker links it statically against musl libc. Building never runs another program, which is why it needs nothing else installed; only downloading packages uses git.
