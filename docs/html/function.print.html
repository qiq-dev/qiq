    Standard library › Output › print

    print

    print — Write values to standard output

    Description

    print(any... values): void

    Writes its arguments on one line, separated by single spaces, followed by a newline. print is a statement built into the language, so it can't be passed around or redeclared.

    Parameters

    values
    Zero or more values of any type except void.

    Return values

    Nothing; print is a statement.

    Examples

    Example #1 Scalars, containers, and objects

    class Square {}
print("age:", 36, 2.5, true);
print([1, 2, 3], ["a", "b,c"]);
print({"ada" => [true, false]});
print(new Square());
print();
print("done");
    Output
    age: 36 2.5 1
[1, 2, 3] ["a", "b,c"]
{"ada" => [true, false]}
Square

done

    Notes

    Note: At the top level, booleans print as 1 and 0; inside arrays and maps they print as true and false, and strings and chars are quoted, so the output reads like a qiq literal.
