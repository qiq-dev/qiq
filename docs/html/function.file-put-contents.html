    file_put_contents

    file_put_contents — Write a string to a file

    Description

    file_put_contents(string path, string data, bool append = false): int

    Import it with import file_put_contents from "std/file";

    Writes data to the file at path.

    Parameters

    path
    The file to write. It's created if it doesn't exist.
    data
    The text to write.
    append
    When true, add to the end of the file instead of replacing its contents.

    Return values

    The number of bytes written (UTF-8 characters can take more than one).

    Errors/Exceptions

    • FileNotFoundException if the path (or a directory in it) doesn't exist.
    • PermissionDeniedException if access is denied.
    • IOException for other failures; the two exceptions above extend it, so catching IOException catches all three.

    Examples

    Example #1 Replacing and appending

    import file, file_put_contents from "std/file";

int a = file_put_contents("log.txt", "started\n");
int b = file_put_contents("log.txt", "héllo\n", append: true);
print(a, b);
print(file("log.txt"));
    Output
    8 7
["started", "héllo"]
