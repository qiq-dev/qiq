    htmlspecialchars

    htmlspecialchars — Escape text for HTML

    Description

    htmlspecialchars(string text): string

    Replaces &, <, >, ", and ' with HTML entities, as PHP's htmlspecialchars does by default, so text from users can be put in an HTML page or attribute without being read as markup.

    Parameters

    text
    The text to escape.

    Return values

    The escaped text.

    Examples

    Example #1 Escaping user input

    string name = "<b>Tom</b> & 'Jerry'";
print("<p>Hello, " + htmlspecialchars(name) + "</p>");
    Output
    <p>Hello, &lt;b&gt;Tom&lt;/b&gt; &amp; &#039;Jerry&#039;</p>
