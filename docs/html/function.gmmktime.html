    gmmktime

    gmmktime — Build a timestamp from a UTC date and time

    Description

    gmmktime(int hour, int minute = 0, int second = 0, int month = 1, int day = 1, int year = 1970): int

    Import it with import gmmktime from "std/time";

    Like mktime, but the date and time are in UTC. Out-of-range values roll over the same way.

    Parameters

    hour
    The hour, 0 to 23.
    minute
    The minute.
    second
    The second.
    month
    The month, 1 to 12.
    day
    The day of the month.
    year
    The year, such as 2026.

    Return values

    The timestamp.

    Errors/Exceptions

    • InvalidArgumentException if the date is outside the range the calendar can represent.

    Examples

    Example #1 Date arithmetic

    import gmdate, gmmktime from "std/time";

int start = gmmktime(0, year: 2026, month: 1, day: 31);
int nextMonth = gmmktime(0, year: 2026, month: 2, day: 31);
print(gmdate("Y-m-d", start), gmdate("Y-m-d", nextMonth));
print((gmmktime(0, year: 2027) - gmmktime(0, year: 2026)) / 86400);
    Output
    2026-01-31 2026-03-03
365
