Variables

Declaring variables

Declare a variable with its type and an initial value. Arrays and maps may be declared without one, and start empty.

```qiq int count = 0; string name = "Ada"; int[] later; map[string, int] counts; counts["a"] = 1; print(count, name, counts); ``` ```output 0 Ada {"a" => 1} ```

Type inference

Assigning to a name that hasn't been declared declares it, with the type of the value:

```qiq num = 123; // int greeting = "hi"; // string words = ["a", "b"]; // string[] print(num + 1, greeting, words); ``` ```output 124 hi ["a", "b"] ```

The type is fixed at that point, so a later num = "text"; is an error. Because there is no declaration keyword, a misspelled name in an assignment silently declares a new variable, so watch for typos. An empty literal such as [] or {} has no type of its own, so x = []; is an error; declare the type instead: int[] x = [];.

Reassignment

Variables and function parameters can be reassigned with name = value;. The new value must have the variable's declared type; an object variable can hold any object of its class or a subclass, and an interface variable any class that implements it.

```qiq int total = 0; foreach ([5, 10, 15] as value) { total = total + value; } string[] names = ["a"]; names = explode(",", "x,y"); print(total, names); ``` ```output 30 ["x", "y"] ```

Walking a linked structure reassigns an object variable:

```qiq class Node { public int value; public Node next; function __construct(int value, Node next = null) { this->value = value; this->next = next; } } Node list = new Node(1, new Node(2, new Node(3))); int total = 0; Node current = list; while (current != null) { total += current->value; current = current->next; } print(total); ``` ```output 6 ```

foreach loop variables, caught exceptions, and this can't be reassigned.

Updating a value

count++; adds 1 to an int or double and count--; subtracts 1. A compound assignment combines a value with the one already there: total += price; is the same as total = total + price;. Because + joins strings, text += "!"; appends.

```qiq int[] scores = [70, 85]; scores[0] += 5; map[string, int] seen = {"ada" => 1}; seen["ada"]++; string greeting = "Hello"; greeting += ", world"; print(scores, seen, greeting); ``` ```output [75, 85] {"ada" => 2} Hello, world ```
  • They work on anything that can be assigned: variables, array elements, map entries, properties, and static properties. The types allowed and the errors are those of the assignment written out, so stock["kiwis"]++; throws KeyNotFoundException when there's no "kiwis" key, as reading stock["kiwis"] would. To count, write counts[word] = (counts[word] ?? 0) + 1;.
  • What's being updated is worked out once: items[next()] += 1; calls next() once. Its current value is read, then the right side is evaluated, then the result is stored.
  • They are statements, not expressions, so print(i++), a[i++] = 0, and n = ++i are errors. Write i++; on its own, then use i. As a statement, i++ and ++i are the same.
Note: PHP's ++ and -- can be used inside expressions, where $i++ and ++$i give different values; qiq allows them only as statements, which is where they're clear. PHP also treats a missing array key as 0 or "" in $counts[$word]++, with a warning; qiq throws instead.

null

A string, char, array, map, or object variable can hold null, meaning no value: assign it with name = null; or declare Node head = null;. Properties, array elements, map values, arguments, and return values of those types can be null too. Test for it with == null; using a null value, such as calling a method on it, throws RuntimeException. Numbers and bools can't be null.

Scope

A variable is visible from its declaration to the end of the block that contains it. An assignment inside an if, loop, or switch updates a variable declared outside it, while a variable declared inside a block is visible only within that block. Each function has its own variables; top-level variables aren't visible inside functions.

```qiq int outer = 1; if (outer > 0) { outer = 2; // updates the outer variable int inner = 3; // visible only in this block print(inner); } print(outer); ``` ```output 3 2 ```

Each declaration must use a new name within its scope; declaring the same name twice is an error.
