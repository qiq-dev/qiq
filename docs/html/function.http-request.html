    http_request

    http_request — Send an HTTP request

    Description

    http_request(string method, string url, string body = null, map[string, string] headers = null, int timeout = 30): Response

    Import it with import http_request from "std/http";

    Sends the request, follows redirects, and returns the final Response. Set a Content-Type header to describe a body, such as application/json.

    Parameters

    method
    The method, such as GET, POST, PUT, PATCH, DELETE, or HEAD; any case.
    url
    An http:// or https:// URL.
    body
    The request body, sent as is; null for none.
    headers
    Headers to send, added to the defaults.
    timeout
    Seconds to wait for each connect, read, and write.

    Return values

    The response, whatever its status.

    Errors/Exceptions

    • NetworkException if the host can't be found, refuses the connection, times out, closes the connection early, or fails the TLS certificate check.
    • HttpException after more than 10 redirects.
    • InvalidArgumentException for a URL that isn't http or https, contains credentials, or has an invalid port, and for header names or values with line breaks.

    Examples

    Example #1 Updating a resource

    import http_request, Response from "std/http";

Response r = http_request("PUT", "https://api.example.com/items/7",
                          json_encode({"name" => "Lamp"}),
                          {"Content-Type" => "application/json", "Authorization" => "Bearer " + token});
if (!r->ok()) {
    print("failed:", r->status, r->text());
}
