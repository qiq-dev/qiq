    ucfirst

    ucfirst — Make a string's first character uppercase

    Description

    ucfirst(string text): string

    Returns text with its first character converted to uppercase, using the same rules as strtoupper.

    Parameters

    text
    The input string.

    Return values

    The resulting string.

    Errors/Exceptions

    • RuntimeException if a string argument is null (for example an unset element of a new string[n] array).

    Examples

    Example #1 Basic use

    print(ucfirst("élan"));
print(ucfirst("hello world"));
    Output
    Élan
Hello world
