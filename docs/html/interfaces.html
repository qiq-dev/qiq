    Interfaces

    An interface declares methods that implementing classes must provide. Interface methods have no body and are always public; a missing return type means void.

    interface Shape {
    function area(): int;
    function name(): string;
}

class Square implements Shape {
    private int side;
    function __construct(int side) { this->side = side; }
    function area(): int { return this->side * this->side; }
    function name(): string { return "square"; }
}

class Rect implements Shape {
    private int w;
    private int h;
    function __construct(int w, int h) { this->w = w; this->h = h; }
    function area(): int { return this->w * this->h; }
    function name(): string { return "rectangle"; }
}

function describe(Shape shape): void {
    print(shape->name(), shape->area());
}

Shape[] shapes = [new Square(3), new Rect(2, 5)];
foreach (shapes as shape) {
    describe(shape);
}
    Output
    square 9
rectangle 10

    Rules

    • A class can implement several interfaces, class A implements B, C, and combine them with inheritance: class Child extends Base implements Named.
    • An interface can extend other interfaces: interface Scalable extends Shape.
    • A concrete class must implement every interface method as a public method with the same parameter and return types. The implementation may be inherited from a parent class. An abstract class may leave interface methods to its subclasses.
    • Interfaces can't declare properties, constructors, static methods, or final methods, and can't be instantiated. They must be declared before use.

    Interface types and dispatch

    An interface name can be used as the type of a variable, parameter, return value, or array element, and holds an object of any implementing class. Calls through it run the object's own implementation, chosen at run time from a table indexed by the object's class.

    Defaults in interface methods

    Interface methods can have optional parameters. An implementation may declare different defaults, and a call always uses the defaults of the method that actually runs:

    interface Template {
    function render(string text, bool escape = true): string;
}
class Page implements Template {
    function render(string text, bool escape = true): string {
        if (escape) {
            return "escaped " + text;
        }
        return text;
    }
}
class RawPage implements Template {
    function render(string text, bool escape = false): string {
        if (escape) {
            return "escaped " + text;
        }
        return text;
    }
}
Template[] views = [new Page(), new RawPage()];
foreach (views as view) {
    print(view->render("<p>"));
}
    Output
    escaped <p>
<p>

    An implementation may make a required parameter optional, but not the other way round.
