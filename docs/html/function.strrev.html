    strrev

    strrev — Reverse a string

    Description

    strrev(string text): string

    Returns the characters of text in reverse order. Unlike PHP's byte-wise strrev, multi-byte UTF-8 characters stay intact.

    Parameters

    text
    The string to reverse.

    Return values

    The reversed string.

    Errors/Exceptions

    • RuntimeException if a string argument is null (for example an unset element of a new string[n] array).

    Examples

    Example #1 Basic use

    print(strrev("añb界"));
    Output
    界bña
