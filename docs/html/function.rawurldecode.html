    rawurldecode

    rawurldecode — Decode a percent-encoded URL path

    Description

    rawurldecode(string text): string

    Import it with import rawurldecode from "std/http";

    Decodes %XX sequences like urldecode, but leaves + as is, as PHP's rawurldecode does. Use it for URL paths, where + is an ordinary character.

    Parameters

    text
    The encoded text.

    Return values

    The decoded text.

    Errors/Exceptions

    • InvalidUtf8Exception if the decoded bytes aren't valid UTF-8.

    Examples

    Example #1 Paths keep their plus signs

    import rawurldecode, urldecode from "std/http";

print(rawurldecode("/files/C%2B%2B+notes.txt"));
print(urldecode("/files/C%2B%2B+notes.txt"));
    Output
    /files/C+++notes.txt
/files/C++ notes.txt
