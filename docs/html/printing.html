    Printing

    print(...) writes its arguments on one line, separated by single spaces, followed by a newline. With no arguments it prints an empty line. See also the print reference page.

    print("age:", 36);
print();
print(1.5, 2.0, 1e20, true, false);
    Output
    age: 36

1.5 2 1e+20 1 0

    Scalars

    • Ints, strings, and chars print as plain text.
    • Doubles print in %g style: up to six significant digits, with no trailing zeros.
    • true and false print as 1 and 0, as in PHP.
    • Bytes print as numbers.
    • null prints as null.

    Arrays, maps, and objects

    Arrays and maps print like qiq literals. Inside them, strings and chars are quoted and escaped, booleans print as true and false, and null elements print as null. Objects print as the name of their actual class, which may be a subclass of the declared type.

    class Shape {}
class Square extends Shape {}

print([1, 2, 3]);
print(["a", "b,c", "say \"hi\""]);
print([[1, 2], [3]], [true, false]);
print({"ada" => 36});
Shape shape = new Square();
print(shape);
    Output
    [1, 2, 3]
["a", "b,c", "say \"hi\""]
[[1, 2], [3]] [true, false]
{"ada" => 36}
Square

    Maps print their entries in the order the keys were added.
