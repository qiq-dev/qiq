Arrays

An array is an ordered list of elements of one type, written type[], like a Python list. It can grow and shrink, and its elements are always numbered from 0 to len(array) - 1, with no gaps. Elements can be of any type: int[], string[], arrays of arrays (int[][]), arrays of maps (map[string, int][]), and arrays of objects (Shape[]).

Creating arrays

```qiq int[] numbers = [1, 2, 3]; // literal int[] zeroes = new int[3]; // three elements, all 0 string[] lines = explode("\n", "a\nb"); // any expression of the right type int[] empty; // an empty array, ready to grow print(numbers, zeroes, lines, empty); ``` ```output [1, 2, 3] [0, 0, 0] ["a", "b"] [] ```
  • A literal's element type comes from its elements, which must all have the same type. An empty [] takes its type from where it's used: int[] xs = [];, xs = [];, or an argument of type int[].
  • The size is never part of the type. new type[size] is a convenience for size elements filled with zeros: numbers start at 0, booleans at false, and strings, chars, arrays, maps, and objects at null. A negative size throws InvalidArgumentException.
  • An array declared without a value starts empty, like a map. To have no array at all, assign null; using a null array throws RuntimeException.

Reading and changing elements

Index with array[index], counting from 0. Every index is checked: one below 0 or not less than the length throws OutOfRangeException.

```qiq string[] names = ["Ada", "Lin"]; names[0] = "Grace"; print(names[0], names); try { print(names[5]); } catch (OutOfRangeException e) { print(e->getMessage()); } ``` ```output Grace ["Grace", "Lin"] index 5 is out of range for an array of length 2 ```

Assigning to an index replaces an existing element; it never grows the array, so names[5] = "x" on a two-element array throws OutOfRangeException, as in Python. Use array[index] ?? default to read an element that may not exist.

Growing and shrinking

These functions change an array in place. Removing an element moves the later ones down, so indexes stay contiguous: after removing element 0, the old element 1 is element 0.

```qiq string[] queue = ["b"]; array_push(queue, "c", "d"); // add to the end array_unshift(queue, "a"); // add to the front print(queue); string first = array_shift(queue); // remove from the front: the rest move down string last = array_pop(queue); // remove from the end print(first, last, queue, queue[0]); string[] removed = array_splice(queue, 0, 1, ["x", "y"]); print(removed, queue); ``` ```output ["a", "b", "c", "d"] a d ["b", "c"] b ["b"] ["x", "y", "c"] ```

Appending is fast: an array keeps spare room and doubles it when it runs out. Adding or removing at the front moves every element, so it takes time proportional to the length.

Arrays are references

Arrays can be passed to and returned from functions, stored in properties, and used as map values. Assigning an array to another variable, or passing it, shares it rather than copying it, so a function can add to an array it's given, and every variable that refers to it sees the change. Array variables can be reassigned to another array of the same type. Comparing two arrays with == compares their elements, not whether they're the same array; see Operators.

```qiq function squares(int count): int[] { int[] values = new int[count]; int i = 0; while (i < count) { values[i] = i * i; i++; } return values; } print(squares(5)); ``` ```output [0, 1, 4, 9, 16] ```

Iterating

Use foreach (array as value) or foreach (array as index => value); see Control structures. The loop checks the array's current length before each element, so elements added during the loop are visited and removed ones aren't. Get the number of elements with len:

```qiq int[] scores = [90, 72, 85]; int total = 0; foreach (scores as score) { total += score; } print(len(scores), total / len(scores)); ``` ```output 3 82 ```

Arrays of arrays

Add a [] for each dimension. Rows are separate arrays, so they can have different lengths, and indexing chains.

```qiq int[][] grid = [[1, 2, 3], [4, 5], [6]]; print(grid[1][0]); grid[2] = [7, 8, 9]; print(grid); int[][] matrix = new int[][2]; // two rows, null until assigned matrix[0] = [1, 0]; matrix[1] = [0, 1]; print(matrix); ``` ```output 4 [[1, 2, 3], [4, 5], [7, 8, 9]] [[1, 0], [0, 1]] ```

Nested literals infer their type from their contents, and an empty inner literal takes its type from the outer one: int[][] rows = [[], [1]];. Arrays of objects may hold subclasses of the element type: Shape[] shapes = [new Square(), new Circle()];.
