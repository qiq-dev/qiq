Operators

Both operands of an arithmetic, comparison, or bitwise operator must have the same type; qiq never converts between types implicitly, so 1 + 1.5 is an error. Use to_double(1) + 1.5 instead.

Arithmetic operators

-aNegation-(3 + 4) is -7
  • Int arithmetic is 64-bit and wraps on overflow.
  • Int / truncates toward zero, and % takes the sign of the left operand: -7 / 2 is -3 and -7 % 3 is -1.
  • Int / or % by zero throws DivisionByZeroException, and an int raised to a negative power throws ArithmeticException. Double arithmetic follows IEEE 754, so 1.0 / 0.0 is inf.
```qiq print(7 / 2, -7 % 3, 2 ** 10, 7.0 / 2.0); print(2 + 3 * 4, (2 + 3) * 4, -2 ** 2); int zero = 0; try { print(1 / zero); } catch (DivisionByZeroException e) { print("caught:", e->getMessage()); } ``` ```output 3 -1 1024 3.5 14 20 -4 caught: division by zero ```

Comparison operators

OperatorTrue whenWorks on
a == b, a != bEqual, not equalint, double, bool, byte, string, char, null, and arrays and maps of those; objects (the same object)
a < b, a > b, a <= b, a >= bOrderingint, double, byte (unsigned), string, char

Comparisons produce a bool and can be used anywhere, not only in if. Strings and chars compare by content; ordering uses UTF-8 byte order, which is Unicode code-point order, not locale-aware alphabetical order. Arrays and maps compare by contents (see below). Objects compare by identity: a == b when they're the same object (see Classes). Functions can only be compared with null. Comparisons can't be chained: write 0 < n && n < 5, not 0 < n < 5.

Comparing arrays and maps

== and != compare two arrays or two maps of the same type by what they hold, like strings, not by whether they're the same array or map:

  • Two arrays are equal when they have the same length and equal elements in the same order.
  • Two maps are equal when they have the same keys, each with an equal value. The order the keys were added in doesn't matter.
  • Elements compare as == compares them on their own, so nested arrays and maps are compared all the way down, 0.0 equals -0.0, and a NaN is unequal to every other value.
  • Arrays and maps that can hold objects or functions can't be compared with ==, and neither can arrays and maps be ordered with < or >; both are compile errors.
```qiq int[] picked = [3, 1, 2]; print(picked == [3, 1, 2], picked == [1, 2, 3], picked != []); map[string, int] stock = {"apples" => 5, "pears" => 2}; print(stock == {"pears" => 2, "apples" => 5}); map[string, int[]] groups = {"odd" => [1, 3], "even" => [2]}; print(groups == {"even" => [2], "odd" => [1, 3]}, groups["odd"] == [3, 1]); ``` ```output 1 0 1 1 1 0 ```

Comparing takes time proportional to the size of what's compared, except that an array or map compared with itself is equal straight away, and two of different lengths are unequal straight away. in_map compares values the same way.

Note: PHP's == on arrays works the same way for values of the same type: lists compare in order, and string-keyed arrays in any order. qiq has no ===, since it never converts between types.

Comparing with null

Strings, chars, arrays, maps, and objects can be compared with null using == and !=, to test whether they have a value. A null string is equal only to null, so comparing one with a string is false rather than an error; ordering a null string with < or > throws RuntimeException.

```qiq string[] names = new string[2]; names[1] = "Ada"; print(names[0] == null, names[1] != null, names[0] == "Ada"); int[] scores = null; if (scores == null) { scores = [90, 85]; } print(scores); ``` ```output 1 1 0 [90, 85] ```

The null coalescing operator

left ?? right gives left, or right when left is missing: a map key that isn't there, an array index out of range (or a null array), or a null value. right is only evaluated when it's needed. It's PHP's ??, and Python's dict.get(key, default).

```qiq map[string, string] settings = {"theme" => "dark"}; string[] args = ["run"]; string name = null; print(settings["theme"] ?? "light", settings["font"] ?? "mono"); print(args[0] ?? "help", args[3] ?? "none"); print(name ?? "anonymous"); print(settings["lang"] ?? settings["locale"] ?? "en"); ``` ```output dark mono run none anonymous en ```
  • The left side must be a map or array element, or a string, char, array, map, or object that can be null. The right side must have the same type, and can be null for those types.
  • ?? has the lowest precedence of all operators and groups to the right, so a ?? b ?? c tries a, then b, then c.
  • As in PHP, a null object earlier in a chain throws rather than counting as missing: user->address->city ?? "" throws when user is null. Write user?->address?->city ?? "" instead, with the nullsafe operator.

String concatenation

+ joins strings and chars in any mix, producing a string: "a" + 'b' is "ab". To include a number, convert it first: "count: " + to_string(n).

Increment, decrement, and compound assignment

x++;, x--;, and compound assignments such as x += v; and x <<= v; update a variable, element, map entry, or property in place. They're statements rather than operators, so they don't appear in the table below; see "Updating a value" under Variables.
