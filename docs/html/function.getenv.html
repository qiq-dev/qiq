    getenv

    getenv — Read an environment variable

    Description

    getenv(string name): string

    Import it with import getenv from "std/os";

    Returns the value of the environment variable name, or null if it isn't set. An empty value is an empty string, not null.

    Parameters

    name
    The variable's name, such as HOME.

    Return values

    The value, or null.

    Errors/Exceptions

    • InvalidUtf8Exception if the value isn't valid UTF-8, and RuntimeException if name is null.

    Examples

    Example #1 With a default

    import getenv from "std/os";

string level = getenv("QIQ_EXAMPLE_LOG_LEVEL") ?? "info";
bool hasPath = getenv("PATH") != null;
print(level, hasPath);
    Output
    info 1

    Notes

    Note: PHP's getenv returns false for a variable that isn't set; qiq returns null, so ?? gives a default.
