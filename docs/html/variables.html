    Variables

    Declaring variables

    Declare a variable with its type and an initial value. Arrays and maps may be declared without one, and start empty.

    int count = 0;
string name = "Ada";
int[] later;
map[string, int] counts;
counts["a"] = 1;
print(count, name, counts);
    Output
    0 Ada {"a" => 1}

    Type inference

    Assigning to a name that hasn't been declared declares it, with the type of the value:

    num = 123;              // int
greeting = "hi";        // string
words = ["a", "b"];     // string[]
print(num + 1, greeting, words);
    Output
    124 hi ["a", "b"]

    The type is fixed at that point, so a later num = "text"; is an error. Because there is no declaration keyword, a misspelled name in an assignment silently declares a new variable, so watch for typos. An empty literal such as [] or {} has no type of its own, so x = []; is an error; declare the type instead: int[] x = [];.

    Reassignment

    Variables and function parameters can be reassigned with name = value;. The new value must have the variable's declared type; an object variable can hold any object of its class or a subclass, and an interface variable any class that implements it.

    int total = 0;
foreach ([5, 10, 15] as value) {
    total = total + value;
}
string[] names = ["a"];
names = explode(",", "x,y");
print(total, names);
    Output
    30 ["x", "y"]

    Walking a linked structure reassigns an object variable:

    class Node {
    public int value;
    public Node next;
    function __construct(int value, Node next = null) {
        this->value = value;
        this->next = next;
    }
}

Node list = new Node(1, new Node(2, new Node(3)));
int total = 0;
Node current = list;
while (current != null) {
    total = total + current->value;
    current = current->next;
}
print(total);
    Output
    6

    foreach loop variables, caught exceptions, and this can't be reassigned.

    null

    A string, char, array, map, or object variable can hold null, meaning no value: assign it with name = null; or declare Node head = null;. Properties, array elements, map values, arguments, and return values of those types can be null too. Test for it with == null; using a null value, such as calling a method on it, throws RuntimeException. Numbers and bools can't be null.

    Scope

    A variable is visible from its declaration to the end of the block that contains it. An assignment inside an if, loop, or switch updates a variable declared outside it, while a variable declared inside a block is visible only within that block. Each function has its own variables; top-level variables aren't visible inside functions.

    int outer = 1;
if (outer > 0) {
    outer = 2;          // updates the outer variable
    int inner = 3;      // visible only in this block
    print(inner);
}
print(outer);
    Output
    3
2

    Each declaration must use a new name within its scope; declaring the same name twice is an error.
