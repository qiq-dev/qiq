    The Socket class

    A Socket is a TCP connection to a server, optionally encrypted with TLS, for talking to services other than HTTP. It works like a File: write text or bytes, and read lines or chunks. The HTTP client is written in qiq on top of it.

    Import it with import Socket from "std/net";

    Class synopsis

    final class Socket {
        static function connect(string host, int port, bool tls = false, int timeout = 30): Socket
        function write(string text): void
        function writeBytes(byte[] data): void
        function readLine(): string
        function read(int length): byte[]
        function readExactly(int length): byte[]
        function readAll(): byte[]
        function close(): void
    }
    MethodDescription
    Socket::connect(host, port, tls, timeout)Connects to a host name or IP address (IPv4 or IPv6). With tls, encrypts the connection and checks the server's certificate and host name against the system's CA certificates (or SSL_CERT_FILE / SSL_CERT_DIR); TLS 1.2 and 1.3 are supported. Every connect, read, and write waits at most timeout seconds.
    write(text), writeBytes(data)Sends a string (as UTF-8) or bytes, all of it.
    readLine()The next line without \n or \r\n, or null once the server has closed the connection. Bytes that aren't valid UTF-8 become U+FFFD, since network data can't be trusted to be well formed.
    read(length)Up to length bytes, as soon as any arrive; an empty array once the connection is closed.
    readExactly(length)Exactly length bytes; throws NetworkException if the connection closes first.
    readAll()Everything until the server closes the connection.
    close()Closes the connection (ending a TLS session properly). Closing twice does nothing. Freeing a Socket doesn't close it.

    Failures throw NetworkException, a subclass of IOException, with messages such as could not find host example.invalid, connection refused by localhost:9, timed out reading from api.example.com:443 after 30 seconds, or TLS certificate of expired.badssl.com:443 is not trusted: The certificate validity has expired.

    Example

    import Socket from "std/net";

Socket s = Socket::connect("example.com", 443, tls: true);
try {
    s->write("HEAD / HTTP/1.1\r\nHost: example.com\r\nConnection: close\r\n\r\n");
    print(s->readLine());      // HTTP/1.1 200 OK
} finally {
    s->close();
}
    Note: A program that uses Socket includes the TLS library (Mbed TLS), so its executable is about 750 KB rather than about 10 KB. Programs that don't use the network aren't affected.
