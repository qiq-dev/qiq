Functions

Declaring functions

A function declares its parameters' types and its return type after a colon. Use void for a function that returns nothing.

```qiq function add(int left, int right): int { return left + right; } function announce(string message): void { print("> " + message); } print(add(5, 2)); announce("done"); ``` ```output 7 > done ```
  • A non-void function must return a value on every path; the compiler checks this. A path may also end by throwing an exception, by an infinite while (true) loop, or by a switch whose every branch returns.
  • A void function may use return; or simply reach the end of its body.
  • Functions can be called before they're declared in the file.
  • A call can stand alone as a statement; if it returns a value, the value is discarded.
  • Parameters can be reassigned inside the function, which doesn't affect the caller's variable. Arrays, maps, and objects are passed by reference, so changing their contents is visible to the caller.

void functions and null

Calling a void function as a value gives null. A void function can also end with return null;.

```qiq function act(): void { print("acting"); } result = act(); if (result == null) { print("act returned null"); } ``` ```output acting act returned null ```

Optional parameters

A parameter with a default value is optional. Optional parameters come after the required ones. A default must be a literal of the parameter's type, or null for a string, char, array, map, or object parameter.

```qiq function greet(string name, string greeting = "Hello", int times = 1): void { print(trim(str_repeat(greeting + ", " + name + "! ", times))); } greet("Ada"); greet("Ada", "Hi"); greet("Ada", "Hi", 2); ``` ```output Hello, Ada! Hi, Ada! Hi, Ada! Hi, Ada! ```

Omitted arguments are filled in by the compiler at each call. For methods, the defaults of the method that actually runs are used, even through an interface; see Interfaces.

Named arguments

Pass an argument by parameter name with name: value. This lets you skip optional parameters, and pass arguments in any order.

```qiq function greet(string name, string greeting = "Hello", int times = 1): void { print(trim(str_repeat(greeting + ", " + name + "! ", times))); } greet("Ada", times: 2); greet(times: 1, greeting: "Hey", name: "Lin"); ``` ```output Hello, Ada! Hello, Ada! Hey, Lin! ```
  • Named arguments come after positional ones, and each parameter can be given only once.
  • Arguments are evaluated in the order written, then passed in parameter order.
  • Named arguments work for functions, methods, static methods, constructors, parent::__construct, and standard library functions.

Variadic parameters

A last parameter written type ...name takes any number of values of that type, including none. Inside the function it's an array, type[]. To pass an array you already have as those values, spread it with ....

```qiq function join(string separator, string ...parts): string { return implode(separator, parts); } print(join("/", "usr", "local", "bin")); string[] path = ["home", "ada"]; print(join("/", ...path)); print(len(join("/"))); ``` ```output usr/local/bin home/ada 0 ```
  • Only the last parameter can be variadic, and it can't have a default: with no values it's an empty array.
  • A spread ...values must be an array of the parameter's type. It can follow single values, as in join("/", "root", ...path), but it must be the last argument, and there can be only one.
  • Parameters before the variadic one can be named; the variadic one itself can't.
  • Methods, static methods, and constructors can be variadic. A method that overrides one keeps its parameter variadic.
  • Used as a value, a variadic function takes the parameter as an array: join is a function(string, string[]): string. Anonymous functions can't be variadic.

Argument checking

The compiler checks every call: the number of arguments, their types, unknown parameter names, and missing required parameters. For example, calling add("5", 2) is the error argument type mismatch calling 'add': expected int, found string.

Functions as values

Functions can be stored in variables and passed around, and written inline without a name; see Anonymous functions.
