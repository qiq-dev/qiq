Exceptions

Throw an exception with throw and handle it with try/catch/finally, as in PHP.

```qiq class ConfigException extends Exception {} function loadPort(string text): int { if (len(text) == 0) { throw new ConfigException("port is empty"); } return to_int(text); } try { print(loadPort("")); } catch (ConfigException e) { print("config error: " + e->getMessage()); } catch (Exception e) { print("other error: " + e->getMessage()); } finally { print("done"); } ``` ```output config error: port is empty done ```

throw

  • throw takes an instance of Exception or a subclass.
  • It ends a code path like return, so a function can end by throwing instead of returning a value.
  • Rethrow a caught exception with throw e;.
  • Exceptions are unchecked: functions don't declare what they throw.

try and catch

  • A try needs at least one catch or a finally.
  • Each catch (ClassName name) matches that class and its subclasses. Catches are tried in order and the first match runs, with name bound to the exception inside the catch block.
  • If no catch matches, the exception propagates to the caller.

finally

finally always runs when control leaves the try: after the block or a catch completes, and also on return, break, continue, or an exception, including one thrown inside a catch. A return or throw inside finally replaces the pending return value or exception, as in PHP.

```qiq function attempt(): string { try { return "from try"; } finally { print("cleaning up"); } } print(attempt()); ``` ```output cleaning up from try ```

Exceptions raised by the runtime

Errors detected while the program runs are exceptions too, so they can be caught: integer division by zero, missing map keys, out-of-range array indexes, null arrays, invalid UTF-8, invalid arguments to standard library functions, and failed file operations. Only running out of memory stops the program immediately.

```qiq int zero = 0; try { print(10 / zero); } catch (DivisionByZeroException e) { print("caught:", e->getMessage()); } map[string, int] ages = {"ada" => 36}; try { print(ages["bob"]); } catch (RuntimeException e) { print("caught a RuntimeException"); } ``` ```output caught: division by zero caught a RuntimeException ```

Uncaught exceptions

An exception that is never caught stops the program with exit status 1 and a message on standard error:

```text qiq: uncaught ConfigException: port is empty ```

Exception classes

The built-in exception classes are available in every file without an import. Your own exceptions extend one of them and inherit the constructor __construct(string message = "", int code = 0) and the methods getMessage() and getCode(). The full hierarchy is listed in Exception classes.

```qiq class ApiException extends Exception {} try { throw new ApiException("not found", 404); } catch (ApiException e) { print(e->getCode(), e->getMessage()); } ``` ```output 404 not found ```
Note: Exceptions are propagated by checking for a pending exception after each call that can throw. There is no stack unwinding, so code that throws nothing pays only a load and a branch per call. Stack traces aren't recorded.
