    gc_collect_cycles

    gc_collect_cycles — Free garbage reference cycles now

    Description

    gc_collect_cycles(): int

    Import it with import gc_collect_cycles from "std/memory";

    Runs the cycle collector immediately. Values are normally freed as soon as nothing refers to them, but objects that refer to each other in a cycle are only freed by the collector, which also runs automatically as possible cycles accumulate. See Memory management.

    Parameters

    This function has no parameters.

    Return values

    How many values were freed.

    Examples

    Example #1 Freeing a cycle

    import gc_collect_cycles from "std/memory";

class Node {
    public Node next;
}

function makeRing(): void {
    Node a = new Node();
    Node b = new Node();
    a->next = b;
    b->next = a;
}

makeRing();
print(gc_collect_cycles());
print(gc_collect_cycles());
    Output
    2
0

    Notes

    Note: There's rarely a need to call this: the collector runs on its own. It can help before measuring memory use, or after building and discarding a large structure full of cycles.
