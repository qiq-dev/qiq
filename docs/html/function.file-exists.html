    file_exists

    file_exists — Check whether a file or directory exists

    Description

    file_exists(string path): bool

    Import it with import file_exists from "std/file";

    Checks whether anything exists at path.

    Parameters

    path
    The path to check.

    Return values

    true if a file or directory exists at path, otherwise false. It never throws for a missing or inaccessible path.

    Errors/Exceptions

    • RuntimeException if path is null.

    Examples

    Example #1 Guarding a read

    import file_exists, file_get_contents from "std/file";

if (file_exists("settings.txt")) {
    print(file_get_contents("settings.txt"));
} else {
    print("no settings");
}
    Output
    no settings
