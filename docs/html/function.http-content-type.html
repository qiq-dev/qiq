    http_content_type

    http_content_type — The Content-Type for a file name

    Description

    http_content_type(string name): string

    Import it with import http_content_type from "std/http/server";

    Looks up the file's extension, in any case, among common web types: HTML, CSS, JavaScript, JSON, text, images, fonts, audio, video, PDF, archives, and WebAssembly. Text types include ; charset=utf-8.

    Parameters

    name
    A file name or path.

    Return values

    The type, or application/octet-stream for an unknown or missing extension.

    Examples

    Example #1 Types by extension

    import http_content_type from "std/http/server";

print(http_content_type("index.HTML"));
print(http_content_type("photos/cat.jpg"));
print(http_content_type("README"));
    Output
    text/html; charset=utf-8
image/jpeg
application/octet-stream
