Tuples

A tuple is a fixed number of values, each with its own type. Its type lists them in parentheses, (int, string), and a tuple is written the same way, (42, "ok"). The usual use is a function that returns more than one thing, without declaring a class for it.

```qiq function minMax(int[] values): (int, int) { int lo = values[0]; int hi = values[0]; foreach (values as value) { if (value < lo) { lo = value; } if (value > hi) { hi = value; } } return (lo, hi); } (int lo, int hi) = minMax([3, 9, 1]); print(f"{lo}..{hi}"); ``` ```output 1..9 ```

Reading the values

A tuple's values are numbered from 0. pair[0] reads the first, with its own type. The index must be a number written in the code, since each position has a different type; pair[i] with a variable is an error, and so is an index past the end.

```qiq (string, int) person = ("Ada", 36); print(person[0], person[1] + 1, person); ``` ```output Ada 37 ("Ada", 36) ```

Tuples can't be changed: person[1] = 37 is an error. Make a new tuple instead. Like objects, arrays, and maps, a tuple can be null, and pair[1] ?? fallback gives the fallback when the tuple or the value is null.

Taking a tuple apart

(int lo, int hi) = minMax(values); declares a variable for each value. Each part can be:

  • a type and a name, int lo, declaring a new variable of that type;
  • a name alone, lo, assigning an existing variable (or, as with any assignment to a new name, declaring one with the value's type);
  • _, for a value you don't need.
```qiq function parse(string text): (int, string) { return (to_int(text), "ok"); } (int value, string status) = parse("42"); (value, _) = parse("7"); print(value, status); int a = 1; int b = 2; (a, b) = (b, a); print(a, b); ``` ```output 7 ok 2 1 ```

The tuple is read once, before any variable is assigned, so (a, b) = (b, a) swaps them. The number of parts must match the tuple's: can't take apart a (int, string) into 3 values: it has 2. Only tuples can be taken apart this way, not arrays.

foreach can take each value apart, as in foreach (people as (string name, int age)), and with keys, foreach (points as key => (int x, int y)).

```qiq (string, int)[] people = [("Ada", 36), ("Lin", 29)]; foreach (people as (string name, int age)) { print(name, age); } ``` ```output Ada 36 Lin 29 ```

Comparing, printing, and JSON

  • == and != compare tuples of the same type value by value, like arrays: (1, "a") == (1, "a") is true. As for arrays, tuples holding objects or functions can only be compared with null.
  • print, to_string, and f-strings write a tuple as it's written in code: (42, "ok").
  • json_encode writes a tuple as a JSON array, [42,"ok"], and json_decode reads one back from an array of exactly that many values.
  • in_array and array_search find tuples by value, as == compares them.

Types

A tuple has 2 to 8 values; for more, a class with named properties is clearer. (x) with one value is just x in parentheses. A tuple's type comes from its values, or from the type it's used as, so (?int, string) maybe = (null, "none"); works where (null, "none") alone couldn't say what the null is. Tuple types can be used anywhere a type can, including arrays, maps, properties, function types, and generic code:

```qiq function swap((A, B) pair): (B, A) { return (pair[1], pair[0]); } print(swap((1, "one")), swap((true, 2.5))); ``` ```output ("one", 1) (2.5, true) ```

Two tuple types are the same when their values' types are, in order; a (Circle, int) isn't a (Shape, int), as with generic classes.
