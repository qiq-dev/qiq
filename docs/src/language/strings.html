Strings and chars

Strings

A string is UTF-8 text in double quotes. Strings are immutable: functions that change text return a new string.

These escapes are recognized in string and char literals:

EscapeMeaning
\nNewline
\rCarriage return
\tTab
\", \'Double and single quote
\\Backslash

There is no variable interpolation; build strings with +.

Raw strings

A string between backticks is raw: backslashes are just backslashes, and it ends at the next backtick, so it can span lines. Raw strings suit regular expressions, Windows paths, and longer text such as SQL. A raw string can't contain a backtick; join one on with + if you need it.

```qiq string pattern = `^\d{4}-\d{2}$`; // the same as "^\\d{4}-\\d{2}$" string path = `C:\Users\ada`; string sql = ` SELECT name FROM users WHERE active = 1`; print(pattern, path); print(len(pattern) == len("^\\d{4}-\\d{2}$")); ``` ```output ^\d{4}-\d{2}$ C:\Users\ada 1 ```

Chars

A char is exactly one Unicode character in single quotes, such as 'a', 'é', or '界'. Iterating over a string with foreach gives its chars.

Concatenation

+ joins strings and chars in any mix and produces a string. Numbers must be converted first with to_string.

```qiq string name = "wörld"; char mark = '!'; print("hello, " + name + mark); print('é' + 'ü'); print("count: " + to_string(42)); ``` ```output hello, wörld! éü count: 42 ```

Characters, not bytes

Every standard library position and length counts characters (Unicode scalar values), not bytes:

```qiq string text = "héllo wörld"; print(len(text)); print(substr(text, 6)); print(strrev("añb界")); foreach ("aé" as position => character) { print(position, character); } ``` ```output 11 wörld 界bña 0 a 1 é ```

To work with the underlying bytes, convert with string_to_bytes and bytes_to_string.

Comparing strings

== and != compare contents. <, >, <=, and >= compare in UTF-8 byte order, which is Unicode code-point order, not locale-aware alphabetical order. Canonically equivalent spellings (such as a precomposed é and e followed by a combining accent) are not treated as equal.

String functions

len(text) counts characters, and works on arrays and maps too. See Strings in the standard library for substr, sprintf, strpos, str_replace, explode, implode, trim, case conversion, and more.
