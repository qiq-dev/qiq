    The Response class

    The result of http_request, http_get, and http_post, like a Response in Python's requests.

    Import it with import Response from "std/http";

    Class synopsis

    class Response {
        public int status;
        public string reason;
        public map[string, string] headers;
        public byte[] bytes;
        public string url;
        function text(): string
        function header(string name): string
        function ok(): bool
        function raiseForStatus(): void
    }
    MemberDescriptionIn requests
    status, reasonThe status code and phrase, such as 200 and OKstatus_code, reason
    headersThe response headers, with lowercase names; a header sent more than once has its values joined with , headers
    bytesThe body as bytes, for any content, including images and archivescontent
    text()The body as a string; throws InvalidUtf8Exception if it isn't UTF-8text
    header(name)One header, by name in any case, or nullheaders[name]
    urlThe URL that answered, after redirectsurl
    ok()Whether the status is below 400ok
    raiseForStatus()Throws HttpException for a 4xx or 5xx status, with the status as its coderaise_for_status()

    For JSON, decode the text into the type you expect: User user = json_decode(r->text());. There's no r->json(), because json_decode takes its type from where it's used.

    Example

    import http_get, Response from "std/http";

Response r = http_get("https://example.com/missing");
print(r->status, r->ok(), r->header("Content-Type"));
try {
    r->raiseForStatus();
} catch (HttpException e) {
    print(e->getCode(), e->getMessage());   // 404 404 Client Error: Not Found for https://example.com/missing
}
