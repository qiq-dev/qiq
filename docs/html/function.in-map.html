    in_map

    in_map — Check whether a map has a value

    Description

    in_map(V value, map[K, V] map): bool

    Returns whether any entry of map has value. Numbers and bools compare by value, strings and chars by content, and arrays, maps, and objects by identity: the same instance, not an equal one.

    Parameters

    value
    The value to look for, of the map's value type.
    map
    The map.

    Return values

    true if the value is present.

    Errors/Exceptions

    • RuntimeException if the map is null. A value of the wrong type is a compile error.

    Examples

    Example #1 Looking for a value

    map[string, string] capitals = {"France" => "Paris", "Japan" => "Tokyo"};
print(in_map("Tokyo", capitals), in_map("Rome", capitals));
    Output
    1 0

    Notes

    Note: This checks every entry, so it takes time proportional to the size of the map. PHP's equivalent is in_array.
