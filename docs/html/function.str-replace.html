    str_replace

    str_replace — Replace all occurrences of a substring

    Description

    str_replace(string search, string replace, string subject): string

    Returns subject with every occurrence of search replaced by replace, scanning from left to right. The argument order is PHP's: what to find, what to put, where.

    Parameters

    search
    The value to look for.
    replace
    The replacement for each occurrence of search.
    subject
    The string to search and replace in.

    Return values

    The resulting string. If search is empty, subject is returned unchanged.

    Errors/Exceptions

    • RuntimeException if a string argument is null (for example an unset element of a new string[n] array).

    Examples

    Example #1 Replacing text

    print(str_replace("ö", "oe", "héllo wörld"));
print(str_replace("a", "", "banana"));
    Output
    héllo woerld
bnn
