    Control structures

    if / else

    The condition must be a bool. Braces are required.

    int age = 30;
if (age >= 18 && age <= 65) {
    print("working age");
} else {
    print("not working age");
}
    Output
    working age

    Chain conditions with else if:

    function grade(int score): string {
    if (score >= 90) {
        return "A";
    } else if (score >= 80) {
        return "B";
    } else {
        return "C";
    }
}
print(grade(95), grade(85), grade(70));
    Output
    A B C

    PHP's one-word elseif isn't supported; write else if. To compare one value against several constants, switch is clearer.

    while

    while repeats its body while the condition is true, testing it before each iteration.

    int i = 0;
while (i < 3) {
    print(i);
    i = i + 1;
}
    Output
    0
1
2

    A function can end with while (true) { ... } instead of a return when the loop has no break and only leaves by returning or throwing.

    foreach

    foreach (collection as value) visits each element of an array, each value of a map, or each character of a string. foreach (collection as key => value) also binds the index (for arrays and strings, counting from 0) or the map key.

    foreach (["a", "b"] as index => letter) {
    print(index, letter);
}
foreach ("aé界" as character) {
    print(character);
}
map[string, int] ages = {"ada" => 36};
foreach (ages as name => age) {
    print(name, age);
}
    Output
    0 a
1 b
a
é
界
ada 36

    Strings iterate by Unicode character, not by byte. Maps iterate in the order their keys were added. The loop variables are new variables for each iteration and can't be reassigned.

    Counting with range

    qiq has no C-style for loop. To repeat something a number of times, or count through numbers, loop over range(start, end, step). The end is included, as in PHP, and the step defaults to 1:

    foreach (range(1, 3) as n) {
    print("round", n);
}
foreach (range(10, 0, 5) as index => value) {
    print(index, value);
}
string[] names = ["Ada", "Lin"];
foreach (range(0, len(names) - 1) as i) {
    print(i, names[i]);
}
    Output
    round 1
round 2
round 3
0 10
1 5
2 0
0 Ada
1 Lin

    A foreach over a range of ints doesn't build an array: it compiles to a counting loop, so range(1, 1000000000) costs nothing extra. When end is less than start, the range counts down. For an empty array, range(0, len(names) - 1) would count down from 0 to -1, so loop over the array itself, or check its length first.

    switch

    switch compares a value with each case in order and runs the first match. Cases don't fall through, so no break is needed; list several values in one case with commas. default runs when nothing matches.

    function describe(int status): string {
    switch (status) {
        case 200, 204:
            return "ok";
        case 404:
            return "not found";
        default:
            return "error";
    }
}
print(describe(204), describe(404), describe(500));
    Output
    ok not found error
    • The value can be an int, double, bool, byte, string, or char. Case values are expressions of the same type, tested in order; the switch value is evaluated once.
    • Duplicate literal case values are an error, and so is a case with no statements, because it would silently do nothing (this catches PHP-style stacked case 1: case 2:). Write break; for a case that deliberately does nothing.
    • default can appear anywhere, at most once.
    • A switch with a default in which every branch returns or throws ends a function's code path.

    break and continue

    break leaves the innermost loop or switch. continue skips to the next iteration of the innermost loop; inside a switch inside a loop, it goes to the loop.

    foreach ([1, 2, 3, 4, 5] as n) {
    if (n == 2) {
        continue;
    }
    if (n == 4) {
        break;
    }
    print(n);
}
    Output
    1
3

    When break, continue, or return leaves a try block, its finally block runs first; see Exceptions.
