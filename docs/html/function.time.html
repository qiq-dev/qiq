    time

    time — The current timestamp

    Description

    time(): int

    Import it with import time from "std/time";

    Returns the current time as a timestamp. A timestamp is an int counting seconds since 1970-01-01 00:00:00 UTC.

    Parameters

    This function has no parameters.

    Return values

    Seconds since 1970-01-01 00:00:00 UTC.

    Examples

    Example #1 A deadline one week from now

    import time from "std/time";

int now = time();
int deadline = now + 7 * 24 * 60 * 60;
print(deadline - now);
    Output
    604800
