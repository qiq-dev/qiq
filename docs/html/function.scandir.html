    scandir

    scandir — List the names in a directory

    Description

    scandir(string path): string[]

    Import it with import scandir from "std/file";

    Lists the files and directories inside path.

    Parameters

    path
    The directory to list.

    Return values

    The names, sorted by byte order, without . and ...

    Errors/Exceptions

    • FileNotFoundException if the path (or a directory in it) doesn't exist.
    • PermissionDeniedException if access is denied.
    • IOException for other failures; the two exceptions above extend it, so catching IOException catches all three.
    • IOException if path isn't a directory.
    • InvalidUtf8Exception if a name isn't valid UTF-8.

    Examples

    Example #1 Listing a directory

    import file_put_contents, scandir from "std/file";

int a = file_put_contents("b.txt", "");
int b = file_put_contents("a.txt", "");
foreach (scandir(".") as name) {
    if (str_ends_with(name, ".txt")) {
        print(name);
    }
}
    Output
    a.txt
b.txt

    Notes

    Note: Unlike PHP's scandir, the . and .. entries are left out.
