    is_dir

    is_dir — Check whether a path is a directory

    Description

    is_dir(string path): bool

    Import it with import is_dir from "std/file";

    Checks whether path exists and is a directory.

    Parameters

    path
    The path to check.

    Return values

    true for a directory; false for a file or a missing path.

    Errors/Exceptions

    • RuntimeException if path is null.

    Examples

    Example #1 Basic use

    import is_dir from "std/file";

print(is_dir("."), is_dir("missing"));
    Output
    1 0
