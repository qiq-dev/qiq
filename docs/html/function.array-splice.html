    array_splice

    array_splice — Remove or replace a range of elements

    Description

    array_splice(T[] array, int offset, int length, T[] replacement): T[]

    Removes length elements starting at offset, inserts the elements of replacement in their place, and moves the rest of the array to close or open the gap, as PHP's array_splice does. Offsets and lengths beyond the array's ends are clipped rather than errors. With a length of 0, it only inserts.

    Parameters

    array
    The array to change.
    offset
    Where the range starts. A negative offset counts from the end.
    length
    How many elements to remove; by default, all from offset to the end. A negative length leaves that many elements at the end.
    replacement
    Elements to put in place of the removed ones; by default, none.

    Return values

    The removed elements, as a new array.

    Errors/Exceptions

    • RuntimeException if the array is null.

    Examples

    Example #1 Removing, replacing, and inserting

    int[] a = [1, 2, 3, 4, 5];
print(array_splice(a, 1, 2), a);
print(array_splice(a, -1, 1, [8, 9]), a);
int[] none = array_splice(a, 1, 0, [7]);
print(a);
    Output
    [2, 3] [1, 4, 5]
[5] [1, 4, 8, 9]
[1, 7, 4, 8, 9]

    Example #2 Removing by index

    string[] names = ["Ada", "Lin", "Grace"];
array_splice(names, 1, 1);
print(names, names[1]);
    Output
    ["Ada", "Grace"] Grace
