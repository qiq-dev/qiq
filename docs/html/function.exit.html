    Standard library › Program › exit

    exit

    exit — End the program with an exit status

    Description

    exit(int status = 0): void

    Import it with import exit from "std/os";

    Flushes output and ends the program immediately with status, which the shell sees as $?. Without exit, a program exits with 0, or with 1 after an uncaught exception.

    Parameters

    status
    The exit status, from 0 (success) to 255.

    Return values

    It doesn't return.

    Errors/Exceptions

    • InvalidArgumentException if status is outside 0 to 255.

    Examples

    Example #1 Stopping early

    import argv, exit from "std/os";

print("checking input");
string[] args = argv();
if (len(args) < 2) {
    print("no input given");
    exit(1);
}
print("never printed without an argument");
    Output
    checking input
no input given

    Notes

    Note: finally blocks don't run, as with PHP's exit. To run them, throw an exception and let it reach the top of the program, which exits with status 1.
