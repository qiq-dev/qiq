    JSON

    Converting values to and from JSON. Because qiq is statically typed, json_decode decodes into the type its result is used as (a variable, property, argument, or return value), and checks the JSON against it, so the rest of the program works with ordinary typed values. Both are built into the compiler and can't be redeclared.

    How qiq types map to JSON

    qiq typeJSON
    int, byte, doubleA number. json_decode accepts only whole numbers for int and byte (0 to 255), and any number for double.
    booltrue or false
    string, charA string; a char is a string of one character
    ArraysAn array
    MapsAn object, in insertion order. Keys are strings in JSON, so int, double, bool, and char keys are written as text and read back from it.
    ObjectsAn object with the class's public properties
    null (a string, array, map, or object without a value)null
