    Date and time

    A timestamp is an int counting seconds since 1970-01-01 00:00:00 UTC. Timestamps work like PHP's: get the current one with time, format one with date, and build one with mktime or strtotime. Local time follows the system (the TZ environment variable, or /etc/localtime) until the program calls date_default_timezone_set. Zone data is read from the system's zoneinfo files when the program runs, so compiled programs stay static.

    Format characters

    date and gmdate use PHP's format letters. Any other character is copied as is; put \\ before a letter to print it literally (in a qiq string, "\\T" is the two characters \T).

    Daylight saving time

    Local times are resolved the way PHP resolves them. A time skipped when clocks go forward is read with the offset from before the change, so 02:30 on a night when clocks jump from 02:00 to 03:00 becomes 03:30. A time that occurs twice, when clocks go back, resolves the same way PHP's strtotime does. To avoid the question entirely, work in UTC with gmdate and gmmktime, and convert to local time only for display.
