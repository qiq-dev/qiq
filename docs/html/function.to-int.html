    to_int

    to_int — Convert a value to an int

    Description

    to_int(byte|bool|double|string value): int

    Converts value to an int: a byte widens; true is 1 and false is 0; a double is truncated toward zero; a string must be a whole int such as "-42" (an optional sign, then digits, with no spaces).

    Parameters

    value
    The value to convert.

    Return values

    The converted value.

    Errors/Exceptions

    • InvalidArgumentException if a string isn't an int, or is outside the int range.
    • ArithmeticException if a double is NaN, infinite, or outside the int range.

    Examples

    Example #1 Each source type

    byte b = 200;
print(to_int(b) + 1, to_int(true), to_int(-2.9), to_int("8080"));
try {
    print(to_int("12a"));
} catch (InvalidArgumentException e) {
    print(e->getMessage());
}
    Output
    201 1 -2 8080
"12a" is not an int
