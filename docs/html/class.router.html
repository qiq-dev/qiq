    The Router class

    Sends each request to a handler chosen by its method and path, like Go's http.ServeMux (with the patterns of Go 1.22).

    Import it with import Router from "std/http/server";

    Class synopsis

    final class Router {
        function handle(string pattern, function(Request, ResponseWriter): void handler): void
        function notFound(function(Request, ResponseWriter): void handler): void
        function serve(Request r, ResponseWriter w): void
        function handler(): function(Request, ResponseWriter): void
    }

    Patterns

    A pattern is an optional method and a path: [METHOD ]/path.

    PatternMatches
    /aboutOnly /about, with any method
    GET /aboutOnly /about, with GET or HEAD
    /static//static/ and every path below it; /static is redirected to /static/
    /Every path: what no other pattern matches
    /{$}Only / itself
    /items/{id}/items/7, with r->pathValue("id") = 7; a wildcard matches one non-empty segment, decoded
    /files/{path...}/files/a/b.txt, with path = a/b.txt; only as the last segment

    When several patterns match, the most specific wins: at the first segment where they differ, a fixed name beats {name}, which beats {name...} or a trailing /; then the longer pattern wins, then the one with a method. So /items/new beats /items/{id}, whatever the order they were added in. A path that only matches patterns for other methods gets 405 Method Not Allowed with an Allow header; one that matches nothing gets 404 Not Found, or the notFound handler.

    handle throws InvalidArgumentException for a malformed pattern or one that duplicates an earlier pattern.

    MethodDescription
    handle(pattern, handler)Adds a route
    notFound(handler)Sets the handler for requests that match no pattern
    serve(r, w)Handles a request: finds the route, sets r->params, and calls its handler. Useful in tests, with a Request built by hand.
    handler()The router as a handler, for http_serve and middleware such as http_log

    Example

    import http_serve, Request, ResponseWriter, Router from "std/http/server";

Router router = new Router();
router->handle("GET /{$}", fn(Request r, ResponseWriter w) => w->write("home\n"));
router->handle("GET /items/{id}", fn(Request r, ResponseWriter w) => w->write("item " + r->pathValue("id") + "\n"));
router->handle("GET /items/new", fn(Request r, ResponseWriter w) => w->write("new item form\n"));
router->handle("DELETE /items/{id}", function(Request r, ResponseWriter w): void {
    w->status(204);
});

// Without a server: build a request and call serve().
Request request = new Request("GET", "/items/42", "", "HTTP/1.1", {"host" => "example.com"}, [], "127.0.0.1:5000");
ResponseWriter writer = new ResponseWriter();
router->serve(request, writer);
print(writer->statusCode(), bytes_to_string(writer->bytes()));   // 200 item 42

http_serve(":8080", router->handler());
