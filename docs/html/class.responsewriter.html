    The ResponseWriter class

    Builds the response to a request, like Go's http.ResponseWriter. The server creates one for each request and sends the response when the handler returns, so the status and headers can be changed at any point until then.

    Import it with import ResponseWriter from "std/http/server";

    Class synopsis

    final class ResponseWriter {
        function status(int code): void
        function statusCode(): int
        function header(string name, string value): void
        function getHeader(string name): string
        function write(string text): void
        function writeBytes(byte[] data): void
        function redirect(string url, int code = 302): void
        function error(int code, string message = null): void
        function bytes(): byte[]
    }
    MethodDescription
    status(code)Sets the status code; 200 by default. Throws InvalidArgumentException for a code outside 100–999.
    statusCode()The status code set so far
    header(name, value)Sets a header, replacing one with the same name in any case. Content-Length, Connection, and Transfer-Encoding are set by the server. Throws InvalidArgumentException if the name or value contains a line break.
    getHeader(name)A header set so far, or null
    write(text), writeBytes(data)Appends to the body
    redirect(url, code)Replies with a redirect: sets the status (302 Found by default; 301, 303, 307, and 308 are the others), the Location header, and a short HTML body
    error(code, message)Replaces the body with a plain-text error, by default the status and its reason (404 Not Found), like Go's http.Error
    bytes()The body written so far, for middleware and tests

    Unless the handler sets a Content-Type, the response is sent as text/plain; charset=utf-8.

    Example

    import Request, ResponseWriter from "std/http/server";

router->handle("GET /items/{id}", function(Request r, ResponseWriter w): void {
    Item item = find_item(r->pathValue("id"));
    if (item == null) {
        w->error(404);
        return;
    }
    w->header("Content-Type", "application/json");
    w->write(json_encode(item));
});
