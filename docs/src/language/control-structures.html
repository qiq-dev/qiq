Control structures

if / else

The condition must be a bool. Braces are required.

```qiq int age = 30; if (age >= 18 && age <= 65) { print("working age"); } else { print("not working age"); } ``` ```output working age ```

Chain conditions with else if:

```qiq function grade(int score): string { if (score >= 90) { return "A"; } else if (score >= 80) { return "B"; } else { return "C"; } } print(grade(95), grade(85), grade(70)); ``` ```output A B C ```

PHP's one-word elseif isn't supported; write else if. To compare one value against several constants, switch is clearer.

while

while repeats its body while the condition is true, testing it before each iteration.

```qiq int i = 0; while (i < 3) { print(i); i++; } ``` ```output 0 1 2 ```

A function can end with while (true) { ... } instead of a return when the loop has no break and only leaves by returning or throwing.

foreach

foreach (collection as value) visits each element of an array, each value of a map, each character of a string, or each value of an object that can be iterated. foreach (collection as key => value) also binds the index (for arrays and strings, counting from 0) or the map key.

```qiq foreach (["a", "b"] as index => letter) { print(index, letter); } foreach ("aé界" as character) { print(character); } map[string, int] ages = {"ada" => 36}; foreach (ages as name => age) { print(name, age); } ``` ```output 0 a 1 b a é 界 ada 36 ```

Strings iterate by Unicode character, not by byte. Maps iterate in the order their keys were added. The loop variables are new variables for each iteration and can't be reassigned.

Iterating your own types

foreach also works on objects of classes that implement one of two generic interfaces, available in every file without an import:

  • Iterator<T>, with hasNext(): bool and next(): T, gives values one at a time; foreach calls next() while hasNext() returns true.
  • Iterable<T>, with iterator(): Iterator<T>, is a collection: foreach asks it for a new iterator each time, so it can be looped over more than once.
```qiq class Countdown implements Iterator { private int n; function __construct(int from) { this->n = from; } function hasNext(): bool { return this->n > 0; } function next(): int { this->n--; return this->n + 1; } } class ArrayIterator implements Iterator { private T[] items; private int position = 0; function __construct(T[] items) { this->items = items; } function hasNext(): bool { return this->position < len(this->items); } function next(): T { T item = this->items[this->position]; this->position++; return item; } } class Bag implements Iterable { private T[] items = []; function add(T item): Bag { array_push(this->items, item); return this; } function iterator(): Iterator { return new ArrayIterator(this->items); } } foreach (new Countdown(3) as n) { print(n); } Bag bag = new Bag(); bag->add("a")->add("b"); foreach (bag as i => item) { print(i, item); } ``` ```output 3 2 1 0 a 1 b ```

The standard library's readers work this way too: a File is an Iterator<string> of its lines, a CsvReader an Iterator<string[]> of its records, and a database Cursor an Iterator<Row>, so foreach (File::open("app.log") as line) reads a file a line at a time.

The loop variable has the iterator's type T, and foreach (object as i => value) counts i from 0, as for an array. break, continue, and return work as in any loop, so an iterator can go on forever, as a Fibonacci one can, and the loop stops it. A function can take any collection with a parameter of type Iterable<int>.

Counting with range

qiq has no C-style for loop. To do something n times, loop over range(n), which counts from 0 up to n - 1, and not at all when n is 0 (or less), like for (i = 0; i < n; i++). To count between two numbers, use range(start, end, step): the end is included, as in PHP, and the step defaults to 1.

```qiq string[] names = ["Ada", "Lin"]; foreach (range(len(names)) as i) { print(i, names[i]); } foreach (range(1, 3) as n) { print("round", n); } foreach (range(10, 0, 5) as index => value) { print(index, value); } ``` ```output 0 Ada 1 Lin round 1 round 2 round 3 0 10 1 5 2 0 ```

A foreach over a range of ints doesn't build an array: it compiles to a counting loop, so range(1000000000) costs nothing extra. continue moves on to the next number, which a counter in a while loop has to remember to do itself.

Note: When end is less than start, range(start, end) counts down, as in PHP. So for an empty array, range(0, len(names) - 1) is range(0, -1), which runs twice, with 0 and -1. Count through indexes with range(len(names)), or use foreach (names as i => name).

switch

switch compares a value with each case in order and runs the first match. Cases don't fall through, so no break is needed; list several values in one case with commas. default runs when nothing matches.

```qiq function describe(int status): string { switch (status) { case 200, 204: return "ok"; case 404: return "not found"; default: return "error"; } } print(describe(204), describe(404), describe(500)); ``` ```output ok not found error ```
  • The value can be an int, double, bool, byte, string, char, or enum. Case values are expressions of the same type, tested in order; the switch value is evaluated once. For an enum, they must be its cases, and a switch without a default must handle all of them.
  • Duplicate literal case values are an error, and so is a case with no statements, because it would silently do nothing (this catches PHP-style stacked case 1: case 2:). Write break; for a case that deliberately does nothing.
  • default can appear anywhere, at most once.
  • A switch with a default in which every branch returns or throws ends a function's code path, and so does such a switch on an enum that handles every case.

match

match is an expression: it compares a value with each arm's values in order and gives the result of the first arm that has an equal one. It's switch for choosing a value, without a variable to fill in.

```qiq enum Status { case Active; case Archived; case Draft; } function label(Status status): string { return match (status) { Status::Active => "on", Status::Archived, Status::Draft => "off", }; } int code = 404; string text = match (code) { 200, 204 => "ok", 404 => "not found", default => "error " + to_string(code), }; print(label(Status::Draft), text); ``` ```output off not found ```
  • Arms are separated by commas, with one allowed after the last; an arm lists one or more values, then => and its result. default gives the result when no value matches.
  • The value can be an int, double, bool, byte, string, char, or enum, as for switch. It's evaluated once, and only the chosen arm's result is.
  • The arms' results must have the same type. The match has the type it's used as, such as a variable's or a return type, or else its first arm's; an arm can be null where that type allows it.
  • Without a default, a match on an enum must handle every case, as a switch must. Any other value that matches no arm throws UnhandledMatchException, as in no match arm for 7.
  • match is a keyword only before (...) {, so it can still name a function or variable.

break and continue

break leaves the innermost loop or switch. continue skips to the next iteration of the innermost loop; inside a switch inside a loop, it goes to the loop.

```qiq foreach ([1, 2, 3, 4, 5] as n) { if (n == 2) { continue; } if (n == 4) { break; } print(n); } ``` ```output 1 3 ```

When break, continue, or return leaves a try block, its finally block runs first; see Exceptions.
