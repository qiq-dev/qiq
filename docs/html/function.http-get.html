    http_get

    http_get — Send a GET request

    Description

    http_get(string url, map[string, string] headers = null, int timeout = 30): Response

    Import it with import http_get from "std/http";

    Same as http_request("GET", url, null, headers, timeout).

    Parameters

    url
    An http:// or https:// URL.
    headers
    Headers to send.
    timeout
    Seconds to wait for each connect, read, and write.

    Return values

    The response.

    Errors/Exceptions

    • As for http_request.

    Examples

    Example #1 A query string

    import http_build_query, http_get, Response from "std/http";

Response r = http_get("https://api.example.com/search?" + http_build_query({"q" => "qiq lang", "page" => "2"}));
print(r->status, r->header("content-type"));

    Example #2 Downloading a file

    import file_put_bytes from "std/file";
import http_get, Response from "std/http";

Response r = http_get("https://example.com/logo.png", timeout: 60);
r->raiseForStatus();
int written = file_put_bytes("logo.png", r->bytes);
