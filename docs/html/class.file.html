    The File class

    A File reads or writes a file a piece at a time: a line, or a chunk of bytes. Use it for files too large to load at once, for files you build up gradually, and for standard input and output. To read or write a whole file in one call, the file functions are simpler.

    Import it with import File from "std/file";

    Class synopsis

    final class File {
        static function open(string path, string mode = "r"): File
        static function stdin(): File
        static function stdout(): File
        static function stderr(): File
        function readLine(): string
        function read(int length): byte[]
        function write(string text): void
        function writeBytes(byte[] data): void
        function eof(): bool
        function flush(): void
        function close(): void
    }

    File is final and its constructor is private: get a File from open, stdin, stdout, or stderr.

    Methods

    MethodDescription
    File::open(path, mode)Opens path, relative to the directory the program runs in. See the modes below.
    File::stdin(), File::stdout(), File::stderr()The program's standard streams. Output through File::stdout() and print goes to the same place, in order.
    readLine()The next line without its line ending (\n or \r\n), or null at the end of the file. A last line without a line ending is still returned. Throws InvalidUtf8Exception if the line isn't UTF-8.
    read(length)Up to length bytes: fewer only at the end of the file, and an empty array after it. Works for any file, including binary ones.
    write(text)Writes a string as UTF-8.
    writeBytes(data)Writes raw bytes.
    eof()Whether there's nothing left to read. It looks ahead, so it's true before a read would come back empty. On standard input it waits for input.
    flush()Writes buffered output now.
    close()Flushes and closes the file. Closing twice does nothing, so it's safe in finally. Closing a standard stream only flushes it.

    Modes

    ModeOpens forIf the file existsIf it doesn't
    "r"ReadingReads from the startFileNotFoundException
    "w"WritingEmpties itCreates it
    "a"AppendingWrites go to the endCreates it
    "x"Writing a new fileIOExceptionCreates it

    Add + ("r+", "w+", "a+", "x+") to allow both reading and writing. Files are always opened in binary mode: nothing translates line endings.

    Errors

    Methods throw the same exceptions as the file functions: FileNotFoundException, PermissionDeniedException, or IOException. Using a file after close() throws IOException, an unknown mode or a negative read length throws InvalidArgumentException, and writing a null string or array throws RuntimeException.

    Examples

    Reading line by line

    import File, file_put_contents from "std/file";

int written = file_put_contents("app.log", "INFO started\nERROR disk full\r\nINFO done\nERROR timeout");

File log = File::open("app.log");
try {
    string line = log->readLine();
    while (line != null) {
        if (str_starts_with(line, "ERROR")) {
            print(line);
        }
        line = log->readLine();
    }
} finally {
    log->close();
}
    Output
    ERROR disk full
ERROR timeout

    Writing a file gradually

    import file, File from "std/file";

File report = File::open("squares.csv", "w");
report->write("n,square\n");
int n = 1;
while (n <= 3) {
    report->write(to_string(n) + "," + to_string(n * n) + "\n");
    n = n + 1;
}
report->close();
print(file("squares.csv"));
    Output
    ["n,square", "1,1", "2,4", "3,9"]

    Reading bytes in chunks

    import File, file_put_bytes from "std/file";

int written = file_put_bytes("data.bin", [1, 2, 3, 4, 5, 6, 7]);
File data = File::open("data.bin");
byte[] chunk = data->read(3);
while (len(chunk) > 0) {
    print(chunk);
    chunk = data->read(3);
}
data->close();
    Output
    [1, 2, 3]
[4, 5, 6]
[7]

    Reading standard input

    A program that reads File::stdin() works in a shell pipeline:

    import File from "std/file";

File input = File::stdin();
int count = 0;
while (!input->eof()) {
    string line = input->readLine();
    count = count + 1;
}
print(count, "lines");
    cat app.log | qiq run count_lines.qiq
    Note: A line or chunk is freed as soon as nothing refers to it, so reading a file a piece at a time uses the same small amount of memory however large the file is. Freeing a File doesn't close it; call close(). See Memory management.
