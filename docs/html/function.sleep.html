    sleep

    sleep — Pause for whole seconds

    Description

    sleep(int seconds): void

    Import it with import sleep from "std/time";

    Pauses the program for seconds seconds.

    Parameters

    seconds
    How long to pause.

    Return values

    Nothing. Unlike PHP's, it returns no value.

    Errors/Exceptions

    • InvalidArgumentException if seconds is negative.

    Examples

    Example #1 Retrying after a pause

    import sleep from "std/time";

int attempt = 1;
while (attempt <= 2) {
    print("attempt", attempt);
    sleep(0);
    attempt = attempt + 1;
}
    Output
    attempt 1
attempt 2
