    json_decode

    json_decode — Convert JSON to a typed value

    Description

    json_decode(string text): the type it's used as

    Parses text and builds a value of the type the result is used as, checking that the JSON matches it:

    • The type comes from where the call is used: User user = json_decode(text);, an assignment, a property, an argument, or a return value. Without one, such as in print(json_decode(text)), it's a compile error.
    • For a class, the JSON object's keys are matched to public properties by name. Keys the class doesn't have are ignored, and properties the JSON doesn't mention keep their default (zero, false, or null). The constructor isn't called. The class, and every class reachable through its public properties, must be concrete, which the compiler checks.
    • null is accepted wherever a string, char, array, map, or object is expected. If a key appears twice, the last value wins.

    Parameters

    text
    The JSON text.

    Return values

    The decoded value.

    Errors/Exceptions

    • JsonException if the text isn't valid JSON (syntax error at line 1, column 14: expected a string key), or doesn't match the type, with the path to the value: $.users[2].age: expected int, found a string.

    Examples

    Example #1 Into a class

    class Address {
    public string city;
}
class User {
    public string name;
    public string[] tags;
    public Address address;
}

User user = json_decode("{\"name\": \"Ada\", \"tags\": [\"math\"], \"address\": {\"city\": \"London\"}, \"extra\": 1}");
print(user->name, user->tags, user->address->city);
    Output
    Ada ["math"] London

    Example #2 Into arrays and maps

    int[] ids = json_decode("[3, 1, 2]");
map[string, double[]] series = json_decode("{\"a\": [1, 2.5], \"b\": []}");
print(ids, series["a"], len(series["b"]));
    Output
    [3, 1, 2] [1, 2.5] 0

    Example #3 Handling bad input

    class Order {
    public int quantity;
}

string[] inputs = ["{\"quantity\": 2}", "{\"quantity\": \"two\"}", "{\"quantity\": 2"];
foreach (inputs as input) {
    try {
        Order order = json_decode(input);
        print("ok:", order->quantity);
    } catch (JsonException e) {
        print("rejected:", e->getMessage());
    }
}
    Output
    ok: 2
rejected: $.quantity: expected int, found a string
rejected: syntax error at line 1, column 15: unexpected end of JSON, expected ',' or '}'

    Notes

    Note: PHP's json_decode returns whatever the JSON contains; qiq's builds exactly the declared type, like JSON decoding in Go or Rust. To accept several shapes, decode into a class with all the properties any of them might have.
    Note: JSON is checked in full: text that is both malformed and the wrong shape is reported as a syntax error.
