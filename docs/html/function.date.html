    date

    date — Format a timestamp in the current timezone

    Description

    date(string format, int timestamp = -9223372036854775808): string

    Import it with import date from "std/time";

    Formats timestamp as local time in the current timezone, using PHP's format letters. Characters that aren't format letters are copied unchanged.

    Parameters

    format
    The format, made of the format characters.
    timestamp
    Defaults to the current time. The default value, the smallest int, stands for "now", because qiq defaults must be literals.

    Return values

    The formatted date.

    Errors/Exceptions

    • InvalidArgumentException if the timestamp is outside the range the calendar can represent.
    • RuntimeException if a string argument is null (for example an unset element of a new string[n] array).

    Examples

    Example #1 Common formats

    import date, date_default_timezone_set from "std/time";

date_default_timezone_set("Europe/Paris");
int t = 1795098600;
print(date("Y-m-d H:i:s", t));
print(date("l, F jS Y", t));
print(date("c", t));
print(date("D, d M Y H:i:s O", t));
    Output
    2026-11-19 15:30:00
Thursday, November 19th 2026
2026-11-19T15:30:00+01:00
Thu, 19 Nov 2026 15:30:00 +0100

    Example #2 Escaping letters

    import gmdate from "std/time";

print(gmdate("\\D\\a\\y z \\o\\f Y", 1795098600));
    Output
    Day 322 of 2026
