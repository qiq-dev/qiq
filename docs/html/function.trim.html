    trim

    trim — Strip characters from the beginning and end of a string

    Description

    trim(string text, string characters = " \t\n\r"): string

    Returns text with leading and trailing characters from characters removed.

    Parameters

    text
    The string to trim.
    characters
    The characters to strip. Each character in this string, including multi-byte ones, is stripped wherever it appears at either end. By default: space, tab, newline, and carriage return.

    Return values

    The trimmed string.

    Errors/Exceptions

    • RuntimeException if a string argument is null (for example an unset element of a new string[n] array).

    Examples

    Example #1 Whitespace and other characters

    print("[" + trim("  padded \n") + "]");
print(trim("--==héllo==--", "-="));
    Output
    [padded]
héllo

    Notes

    Note: PHP's .. ranges (such as "a..z") aren't supported; list the characters instead.
