    http_log

    http_log — Log each request to stderr

    Description

    http_log(function(Request, ResponseWriter): void handler): function(Request, ResponseWriter): void

    Import it with import http_log from "std/http/server";

    Returns a handler that calls handler and then writes a line to stderr in the style of php -S: the time, the client's address, the status, the method, the path, and how long the handler took. A handler of this shape that wraps another is often called middleware; write your own the same way.

    Parameters

    handler
    The handler to wrap.

    Return values

    The handler.

    Examples

    Example #1 Logging

    import http_log, http_serve from "std/http/server";

http_serve(":8080", http_log(router->handler()));
// [Fri Nov 20 10:15:02 2026] 127.0.0.1:51234 [200]: GET /hello/Ada (0.1 ms)

    Example #2 Your own middleware

    import getenv from "std/os";
import http_log, http_serve, Request, ResponseWriter from "std/http/server";

function require_token(string token, function(Request, ResponseWriter): void next): function(Request, ResponseWriter): void {
    return function(Request r, ResponseWriter w): void {
        if (r->header("Authorization") != "Bearer " + token) {
            w->error(401);
            return;
        }
        next(r, w);
    };
}
http_serve(":8080", http_log(require_token(getenv("API_TOKEN"), router->handler())));
