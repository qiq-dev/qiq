    HTTP

    HTTP and HTTPS requests in the style of Python's requests module, plus URL encoding. The client is written in qiq (stdlib/http.qiq) on top of the Socket class, and returns a Response. HTTPS uses Mbed TLS, built into qiq, and always checks the server's certificate against the system's CA certificates. Network failures throw NetworkException; error statuses such as 404 don't, until you call raiseForStatus().

    Example

    import http_get, Response from "std/http";

class Repository {
    public string full_name;
    public int stargazers_count;
}

Response r = http_get("https://api.github.com/repos/torvalds/linux",
                      headers: {"Accept" => "application/vnd.github+json"});
r->raiseForStatus();
Repository repo = json_decode(r->text());
print(repo->full_name, repo->stargazers_count);

    What the client does

    • HTTP/1.1, one connection per request. Request bodies are sent with a Content-Length; responses can use Content-Length, chunked transfer encoding, or end when the server closes the connection.
    • Redirects (301, 302, 303, 307, 308) are followed, up to 10. A 303, or a 301 or 302 after a POST, becomes a GET without a body, as in browsers and requests. An Authorization header isn't sent on to a different host.
    • Default headers: User-Agent: qiq-http/1.0, Accept: */*, Accept-Encoding: identity (responses aren't compressed), and Connection: close. Headers you pass replace defaults with the same name, in any case.
    • The timeout limits each connect, read, and write, in seconds, as in requests.
    • Certificates come from the system's CA bundle (as Go finds it), or from the file in SSL_CERT_FILE or the directory in SSL_CERT_DIR. TLS 1.2 and 1.3 are supported.
    • Not supported yet: sessions and cookies, multipart uploads, streaming bodies, compression, proxies, and credentials in URLs.
