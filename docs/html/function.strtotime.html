    strtotime

    strtotime — Parse an ISO 8601 date

    Description

    strtotime(string text): int

    Import it with import strtotime from "std/time";

    Parses a date in one of these ISO 8601 forms:

    • a date: 2026-11-19 (midnight)
    • a date and time, separated by T or a space: 2026-11-19 14:30, 2026-11-19T14:30:00; fractions of a second (14:30:00.250) are accepted and dropped
    • either of those followed by Z or an offset: 2026-11-19T14:30:00Z, +02:00, -0500, +05

    Without Z or an offset, the time is local, in the current timezone.

    Parameters

    text
    An ISO 8601 date, or date and time.

    Return values

    The timestamp.

    Errors/Exceptions

    • InvalidArgumentException if the text isn't one of the forms above, or names a date or time that doesn't exist (such as February 30 or 25:00).
    • RuntimeException if a string argument is null (for example an unset element of a new string[n] array).

    Examples

    Example #1 Dates with and without offsets

    import date_default_timezone_set, gmdate, strtotime from "std/time";

date_default_timezone_set("UTC");
print(strtotime("2026-11-19T14:30:00Z"));
print(strtotime("2026-11-19T16:30:00+02:00"));
print(gmdate("c", strtotime("2026-11-19 09:30-05:00")));
try {
    int t = strtotime("next monday");
} catch (InvalidArgumentException e) {
    print(e->getMessage());
}
    Output
    1795098600
1795098600
2026-11-19T14:30:00+00:00
"next monday" is not an ISO 8601 date

    Notes

    Note: PHP's strtotime also understands phrases such as "next monday" and "+1 week". qiq accepts only ISO 8601, and throws rather than returning false.
