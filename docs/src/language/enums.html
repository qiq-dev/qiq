Enums

An enum is a type with a fixed set of values, its cases. A variable of an enum type holds one of them, so the compiler can check that a value is valid and that a switch handles every case, which int or string constants can't give you. qiq's enums work like PHP's.

```qiq enum Suit { case Hearts; case Diamonds; case Clubs; case Spades; } Suit trump = Suit::Spades; print(trump, trump->name, trump == Suit::Spades); ``` ```output Suit::Spades Spades true ```

Cases

  • Write a case as Enum::Case (or self::Case inside the enum). Each case is a single value: == and != compare cases, and two reads of Suit::Hearts are always equal.
  • Every case has a readonly name property, the case's name as a string.
  • Enum::cases() returns all the cases in the order they're declared.
  • Printing a case prints Enum::Case.
  • Cases can be stored anywhere an object can: in variables, properties, arrays, and map values. They can also be property defaults and parameter defaults: function deal(Suit trump = Suit::Spades).
```qiq enum Direction { case Up; case Down; } foreach (Direction::cases() as direction) { print(direction->name); } ``` ```output Up Down ```

Backed enums

A backed enum gives each case a value, all ints or all strings, written after the enum's name. This is how an enum is stored in a database or sent as JSON. Each case then also has a readonly value, and the enum gets two static methods for going back from a value to its case:

  • Enum::from(value) returns the case with that value, and throws InvalidArgumentException if there's none.
  • Enum::tryFrom(value) returns the case, or null if there's none.
```qiq enum Status: string { case Active = "active"; case Archived = "archived"; } print(Status::Active->value); print(Status::from("archived"), Status::tryFrom("deleted") == null); try { Status::from("deleted"); } catch (InvalidArgumentException e) { print(e->getMessage()); } ``` ```output active Status::Archived true "deleted" is not a valid backing value for enum Status ```

Values must be literals of the backing type, and no two cases can share one.

switch on an enum

A switch can test an enum value; its case values must be cases of that enum. Without a default, the switch must handle every case, so adding a case to an enum makes the compiler point out every switch that needs updating.

```qiq enum Suit { case Hearts; case Diamonds; case Clubs; case Spades; } function color(Suit suit): string { switch (suit) { case Suit::Hearts, Suit::Diamonds: return "red"; case Suit::Clubs, Suit::Spades: return "black"; } } print(color(Suit::Diamonds)); ``` ```output red ```

Leaving out Suit::Spades above is the error switch on enum Suit doesn't handle Suit::Spades; add a case for it, or a default. A switch like this one, with every case handled and every branch returning, ends the function's code path, as a switch with a default does. A null value matches no case, so it throws RuntimeException.

Methods, constants, and interfaces

An enum can have methods (with this as the case they're called on), static methods, and constants, and it can implement interfaces.

```qiq interface HasLabel { function label(): string; } enum Priority: int implements HasLabel { case Low = 1; case High = 10; const Default = 1; function label(): string { return strtolower(this->name) + " (" + to_string(this->value) + ")"; } static function fallback(): Priority { return Priority::from(self::Default); } } HasLabel item = Priority::High; print(item->label(), Priority::fallback()); ``` ```output high (10) Priority::Low ```

Rules

  • An enum can't have properties or a constructor, and it can't be created with new: its cases are its only values.
  • An enum can't extend a class, and classes can't extend it.
  • It can't declare its own cases, from, or tryFrom; a pure enum (without values) has only cases.
  • json_encode writes a backed enum as its value, as PHP does, and throws JsonException for a pure enum. json_decode can't create enums yet: decode the value and read it with from.
  • Maps can't have enum keys, since keys are scalars; use the case's name or value as the key.
  • enum is a keyword only at the start of an enum declaration, so it can still be used as a name.
