    Static members

    Static methods

    A static method belongs to the class, not to an object. Call it with ClassName::method(...), or self::method(...) inside the class.

    class MathUtil {
    static function clamp(int value, int low = 0, int high = 100): int {
        if (value < low) {
            return low;
        }
        if (value > high) {
            return high;
        }
        return value;
    }

    static function percent(int part, int whole): int {
        return self::clamp(part * 100 / whole);
    }
}
print(MathUtil::clamp(150), MathUtil::percent(3, 4));
    Output
    100 75
    • A static method has no this; using it is an error. Instance methods can call static ones.
    • :: is for static members and -> for instance members; using the wrong one is an error that names the right one.
    • Static methods are inherited, follow visibility rules, accept optional and named arguments, and can be final. They can't be abstract, constructors, or implement interface methods.

    A common use is a static factory, which can call a private constructor because it's inside the class:

    class Temperature {
    private double celsius;

    private function __construct(double celsius) {
        this->celsius = celsius;
    }

    static function fromFahrenheit(double value): Temperature {
        return new Temperature((value - 32.0) * 5.0 / 9.0);
    }

    function celsius(): double {
        return this->celsius;
    }
}
print(Temperature::fromFahrenheit(212.0)->celsius());
    Output
    100

    Static properties

    A static property holds one value for the class. It can have a literal initializer; without one it starts at zero, false, or null. Read and assign it with ClassName::name, self::name, parent::name, or static::name.

    class Counter {
    private static int count = 0;
    public static string label = "hits";

    static function increment(): int {
        self::count = self::count + 1;
        return self::count;
    }
}
int first = Counter::increment();
int second = Counter::increment();
print(Counter::label, second);
Counter::label = "visits";
print(Counter::label);
    Output
    hits 2
visits
    • Static properties are private by default, like instance properties.
    • A subclass shares its parent's static property unless it redeclares it, which gives the subclass its own value. A redeclared static property must keep its type.
    • Initializers must be literals, so arrays, maps, and objects start as null and are assigned later.

    Late static binding

    static:: refers to the class a call was made on, which may be a subclass of the class whose code is running; self:: always refers to the class where the code is written. static::method(), static::property, and new static(...) use it, and static as a return type means "an instance of the class the call was made on":

    class Model {
    protected static string table = "models";

    static function tableName(): string {
        return static::table;
    }

    static function create(): static {
        return new static();
    }

    function describe(): string {
        return "a row in " + static::table;
    }
}

class User extends Model {
    protected static string table = "users";

    function greet(): string {
        return "hi";
    }
}

print(Model::tableName(), User::tableName());
User user = User::create();
print(user->greet(), user->describe());
    Output
    models users
hi a row in users
    • In a static method, the called class is the one named in the call (User::create()); in an instance method, it's the object's own class. self:: and parent:: pass the called class along, as in PHP.
    • User::create() above is typed as returning a User, so user->greet() compiles.
    • static:: can call static methods only.
    • new static(...) requires every subclass to be constructible with the same arguments, which is checked at compile time. If the called class is abstract, it throws RuntimeException.
    • A method declared : static can only be overridden by another : static method.
