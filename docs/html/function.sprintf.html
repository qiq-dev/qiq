    sprintf

    sprintf — Format values into a string

    Description

    sprintf(string format, int|double|bool|byte|string|char... values): string

    Returns format with each placeholder replaced by a formatted value, as PHP's sprintf does. A placeholder is written %[argnum$][flags][width][.precision]specifier; %% is a literal percent sign.

    SpecifierFormats the value asExample
    sA string; .precision is the maximum number of characterssprintf("%.3s", "abcdef") is abc
    dAn int-42
    uAn int as unsignedsprintf("%u", -1) is 18446744073709551615
    f, FA double with .precision decimals (default 6)sprintf("%.2f", 3.14159) is 3.14
    e, EScientific notation with .precision decimalssprintf("%.2e", 1234.5) is 1.23e+3
    g, GPlain or scientific notation, whichever is shorter, with .precision significant digitssprintf("%g", 0.00001234) is 1.234e-5
    x, XAn int in hexadecimalsprintf("%x", 255) is ff
    oAn int in octalsprintf("%o", 8) is 10
    bAn int in binarysprintf("%b", 5) is 101
    cThe character with that Unicode code point; width doesn't applysprintf("%c", 233) is é
    Before the widthEffect
    -Left-justify within the width (the default is right)
    +Show a + sign on positive numbers
    0Pad with zeros instead of spaces; a sign stays in front
    'charPad with any character, such as '* or '·

    The width is the minimum number of characters. argnum$ picks a value by position, from 1, so %2$s uses the second value and a value can be used more than once.

    Values are converted as PHP converts them: %d truncates a double and reads the number at the start of a string ("12abc" is 12); %f reads a double from a string. With %s, bools are 1 and 0, and doubles are written like to_string (%g, so 1e+20), where PHP would write 1.0E+20.

    Parameters

    format
    Text with placeholders, described below.
    values
    The values the placeholders use, in order.

    Return values

    The formatted string.

    Errors/Exceptions

    • When format is a string literal, the compiler checks it: an unknown specifier, or fewer values than the placeholders use, is a compile error. Values must be ints, doubles, bools, bytes, strings, or chars.
    • InvalidArgumentException for the same mistakes in a format that isn't a literal, and for %c with a number that isn't a Unicode code point.
    • RuntimeException if a string value or the format is null.

    Examples

    Example #1 Padding and precision

    print(sprintf("%-8s|%6.2f|%05d|%+d", "price", 3.14159, 42, 7));
print(sprintf("%x %X %o %b", 255, 255, 8, 5));
print(sprintf("%'*10s|%-10s|", "right", "left"));
    Output
    price   |  3.14|00042|+7
ff FF 10 101
*****right|left      |

    Example #2 A table of rows

    string[] items = ["Coffee", "Croissant"];
double[] prices = [3.5, 2.25];
int i = 0;
while (i < len(items)) {
    print(sprintf("%-10s %6.2f", items[i], prices[i]));
    i = i + 1;
}
    Output
    Coffee       3.50
Croissant    2.25

    Example #3 Characters, not bytes

    print(sprintf("[%-7s] [%.2s] [%2$s again]", "héllo", "日本語"));
    Output
    [héllo  ] [日本] [日本語 again]

    Notes

    Note: Widths and string precisions count characters, like every length in qiq, where PHP counts bytes. Everything else matches PHP: integers and floating-point numbers are formatted exactly as PHP formats them.
    Note: To print the result, use print(sprintf(...)); there is no separate printf.
