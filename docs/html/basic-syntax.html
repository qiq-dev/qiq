    Basic syntax

    Statements and comments

    A qiq program is a sequence of declarations and statements. Simple statements end with a semicolon; blocks use braces. Whitespace between tokens, including newlines, is ignored. // starts a comment that runs to the end of the line.

    // A complete program: statements run from top to bottom.
int total = 0;
foreach ([1, 2, 3] as value) {
    total = total + value;   // a statement ends with ;
}
print(total);
    Output
    6

    Program structure

    A file contains, in this order:

    1. Any import declarations (see Modules).
    2. Declarations of functions, classes, and interfaces, and top-level statements, in any order. Top-level statements run in order when the program starts.

    Functions can be called before they are declared in the file. Classes and interfaces must be declared before they are used by name, for example as a parent class or a variable's type.

    Identifiers

    Names of variables, functions, classes, properties, and methods start with a letter or underscore and continue with letters, digits, and underscores. Names are case-sensitive. Unlike PHP, variables don't start with $.

    Keywords

    These words are reserved and can't be used as names:

    abstract as bool break byte case catch char class continue default double else extends false final finally foreach function if implements int interface map new null parent print private protected public return static string switch throw true try void while

    A few words are special only in one position, so they can still be used as names elsewhere: import and from (at the start of a file), self (before ::), and this (inside instance methods).

    Errors

    The compiler reports the first error it finds, with the file name and, for syntax errors, the line and column:

    qiq: main.qiq:4:15: expected ';' after declaration
qiq: main.qiq: cannot initialize int variable 'n' with string
