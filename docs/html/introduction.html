    Introduction

    qiq is a statically typed programming language with a syntax familiar to PHP developers. Its compiler turns qiq programs into fast, statically linked native executables for Linux, so a program you build runs on any x86-64 Linux machine without qiq or any libraries installed.

    class Greeter {
    private string name;

    function __construct(string name) {
        this->name = name;
    }

    function greet(string greeting = "Hello"): string {
        return greeting + ", " + this->name + "!";
    }
}

Greeter greeter = new Greeter("Ada");
print(greeter->greet());
print(greeter->greet(greeting: "Welcome"));
    Output
    Hello, Ada!
Welcome, Ada!

    What qiq looks like

    If you know PHP, most of qiq will feel familiar: class, extends, implements, -> and ::, foreach (items as key => value), try/catch/finally, and standard library functions such as substr, explode, and file_get_contents. The main differences:

    • Types are checked at compile time. Variables, parameters, and return values have types, and mistakes such as passing a string where an int is expected are compile errors. qiq never converts between types implicitly; see Conversions.
    • No $ on variables, and this instead of $this.
    • Strings are UTF-8, and string functions count characters rather than bytes: len("héllo") is 5.
    • Arrays and maps are separate types: int[] for a list, map[string, int] for key/value pairs, written [1, 2] and {"a" => 1}.
    • It compiles to a native executable instead of running in an interpreter, with qiq run for a PHP-style "just run it" workflow.

    Features at a glance

    • Types: int (64-bit), double, bool, byte, string, char, arrays, maps, and classes.
    • Functions with optional parameters and named arguments.
    • Classes with inheritance, abstract and final classes, static members and late static binding, and interfaces.
    • Exceptions with try/catch/finally; runtime errors such as division by zero are exceptions too.
    • Modules: import Page from "views/page";
    • A standard library for strings, files, and conversions.
