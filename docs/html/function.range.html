    range

    range — An array of numbers or characters from start to end

    Description

    range(int|double|char start, int|double|char end, int|double step = 1): int[]|double[]|char[]

    Returns the values from start to end, as PHP's range does:

    • The result is int[] for ints, double[] if any argument is a double, and char[] for two chars, which count by Unicode code point (range('a', 'e'), range('α', 'ε')).
    • The end is included: range(1, 3) is [1, 2, 3]. When end is less than start, the values count down: range(3, 1) is [3, 2, 1].
    • For doubles, value i is start + i * step, stopping at end, so rounding can leave the end out: range(0.0, 0.3, 0.1) has three values.

    In foreach (range(...) as i) over ints, no array is built: the loop just counts.

    Parameters

    start
    The first value.
    end
    The last value, which is included if the steps land on it.
    step
    The distance between values: positive, and for chars an int.

    Return values

    The values, as a new array.

    Errors/Exceptions

    • InvalidArgumentException if the step is 0, negative for an increasing range, or larger than the distance from start to end (unless they're equal), or if a range used as an array would have more than 231 elements.
    • Arguments of other types, or a char mixed with a number, are compile errors.

    Examples

    Example #1 Ints, doubles, and chars

    print(range(1, 5), range(10, 0, 4));
print(range(0, 1, 0.25), range('a', 'e', 2));
    Output
    [1, 2, 3, 4, 5] [10, 6, 2]
[0, 0.25, 0.5, 0.75, 1] ['a', 'c', 'e']

    Example #2 Counting in a loop

    int total = 0;
foreach (range(1, 100) as n) {
    total = total + n;
}
print(total);
    Output
    5050

    Notes

    Note: qiq has no C-style for loop; foreach over range covers counting loops.
