    array_unshift

    array_unshift — Add values to the front of an array

    Description

    array_unshift(T[] array, T... values): void

    Inserts the values at the front of the array, moving the existing elements up. This takes time proportional to the array's length.

    Parameters

    array
    The array to change.
    values
    One or more values; they end up in the order given.

    Return values

    Nothing. (PHP's returns the new length; use len(array).)

    Errors/Exceptions

    • RuntimeException if the array is null. A value of the wrong type is a compile error.

    Examples

    Example #1 Adding to the front

    int[] numbers = [3, 4];
array_unshift(numbers, 1, 2);
print(numbers);
    Output
    [1, 2, 3, 4]
