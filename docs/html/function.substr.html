    substr

    substr — Return part of a string

    Description

    substr(string text, int start, int length = 9223372036854775807): string

    Returns the characters of text starting at start, at most length of them. Positions and lengths count characters, not bytes, following PHP's rules for negative values.

    Parameters

    text
    The input string.
    start
    The character position to start at, counting from 0. A negative start counts from the end: -1 is the last character.
    length
    The maximum number of characters to return. A negative length leaves that many characters off the end. By default, everything to the end of the string.

    Return values

    The extracted part, or an empty string when start is past the end or the range is empty.

    Errors/Exceptions

    • RuntimeException if a string argument is null (for example an unset element of a new string[n] array).

    Examples

    Example #1 Positive and negative positions

    string text = "héllo wörld";
print(substr(text, 6));
print(substr(text, 1, 4));
print(substr(text, -5, 3));
print(substr(text, 0, -6));
    Output
    wörld
éllo
wör
héllo
