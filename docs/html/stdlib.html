    Standard library

    The everyday parts of the standard library are available in every file without an import, like PHP's built-in functions: the general functions (len, print, the conversions, and the array, map, and JSON functions), the string functions, and the exception classes. They can't be redeclared: declaring your own substr is a compile error. The rest is in modules that you import by name, like Go's packages:

    Import pathContents
    std/fileFiles and the File class
    std/timeDate and time
    std/osThe program: arguments, exit status, environment
    std/memorygc_collect_cycles
    std/netThe Socket class
    std/httpThe HTTP client and URL encoding
    std/http/serverThe HTTP server
    import File, file_get_contents from "std/file";
import date from "std/time";

    Names from these modules are free for your own code when you don't import them: a program can declare its own File class or time function. Each function's page shows its import line. Strings are UTF-8, and every position and length counts characters, not bytes.

    General

    len works on several types, so like to_int and the other conversions it's part of the compiler rather than declared in stdlib/. gc_collect_cycles controls memory management.

    FunctionDescription
    lenThe length of a string, array, or map
    gc_collect_cyclesFree garbage reference cycles now

    Strings

    Functions for working with string values. Strings are UTF-8, and positions and lengths count characters (Unicode scalar values), so len("héllo") is 5 (see len). Concatenate with +; see Strings and chars.

    FunctionDescription
    substrReturn part of a string
    strposFind the position of the first occurrence of a substring
    str_containsDetermine if a string contains a substring
    str_starts_withCheck if a string starts with a given substring
    str_ends_withCheck if a string ends with a given substring
    str_replaceReplace all occurrences of a substring
    htmlspecialcharsEscape text for HTML
    sprintfFormat values into a string
    str_repeatRepeat a string
    strtoupperMake a string uppercase
    strtolowerMake a string lowercase
    ucfirstMake a string's first character uppercase
    strrevReverse a string
    trimStrip characters from the beginning and end of a string
    explodeSplit a string by a separator
    implodeJoin array elements with a string
    string_to_bytesGet a string's UTF-8 bytes
    bytes_to_stringDecode UTF-8 bytes into a string

    Arrays

    range builds arrays of numbers or characters; the other functions grow and shrink arrays in place, like Python's list methods. They're built into the compiler, because they work with any element type. Indexes always run from 0 to len(array) - 1: removing an element moves the later ones down. Every variable that refers to the array sees the change.

    FunctionDescription
    rangeAn array of numbers or characters from start to end
    array_pushAdd values to the end of an array
    array_popRemove and return the last element
    array_shiftRemove and return the first element
    array_unshiftAdd values to the front of an array
    array_spliceRemove or replace a range of elements

    Maps

    Functions for maps. They're built into the compiler, because they work with any key and value types. Maps keep insertion order, so map_keys and map_values return entries in the order they were added. To read a key with a default, use map[key] ?? default.

    FunctionDescription
    map_key_existsCheck whether a map has a key
    map_keysThe keys of a map, as an array
    map_valuesThe values of a map, as an array
    in_mapCheck whether a map has a value
    unsetRemove an entry from a map

    Files

    Functions for reading and writing files and directories. Paths are relative to the directory the program runs in, not to the source file. Failures throw exceptions; see Exception classes.

    FunctionDescription
    file_get_contentsRead an entire file into a string
    file_put_contentsWrite a string to a file
    fileRead a file into an array of lines
    file_existsCheck whether a file or directory exists
    is_fileCheck whether a path is a regular file
    is_dirCheck whether a path is a directory
    scandirList the names in a directory
    file_get_bytesRead an entire file as raw bytes
    file_put_bytesWrite raw bytes to a file

    Date and time

    A timestamp is an int counting seconds since 1970-01-01 00:00:00 UTC. Timestamps work like PHP's: get the current one with time, format one with date, and build one with mktime or strtotime. Local time follows the system (the TZ environment variable, or /etc/localtime) until the program calls date_default_timezone_set. Zone data is read from the system's zoneinfo files when the program runs, so compiled programs stay static.

    FunctionDescription
    timeThe current timestamp
    microtimeThe current time with microseconds
    hrtimeA monotonic clock in nanoseconds
    dateFormat a timestamp in the current timezone
    gmdateFormat a timestamp in UTC
    mktimeBuild a timestamp from a local date and time
    gmmktimeBuild a timestamp from a UTC date and time
    checkdateCheck whether a date exists
    strtotimeParse an ISO 8601 date
    date_default_timezone_setSet the timezone for local times
    date_default_timezone_getThe current timezone's name
    sleepPause for whole seconds
    usleepPause for microseconds

    JSON

    Converting values to and from JSON. Because qiq is statically typed, json_decode decodes into the type its result is used as (a variable, property, argument, or return value), and checks the JSON against it, so the rest of the program works with ordinary typed values. Both are built into the compiler and can't be redeclared.

    FunctionDescription
    json_encodeConvert a value to JSON
    json_decodeConvert JSON to a typed value

    HTTP

    HTTP and HTTPS requests in the style of Python's requests module, plus URL encoding. The client is written in qiq (stdlib/http.qiq) on top of the Socket class, and returns a Response. HTTPS uses Mbed TLS, built into qiq, and always checks the server's certificate against the system's CA certificates. Network failures throw NetworkException; error statuses such as 404 don't, until you call raiseForStatus().

    FunctionDescription
    http_requestSend an HTTP request
    http_getSend a GET request
    http_postSend a POST request
    urlencodePercent-encode text for a query string
    rawurlencodePercent-encode text for a URL path
    urldecodeDecode percent-encoded text
    rawurldecodeDecode a percent-encoded URL path
    http_build_queryBuild a query string from a map

    HTTP server

    An HTTP server in the style of Go's net/http. A handler is any function(Request, ResponseWriter): void, usually an anonymous function: it reads the Request and writes the response with the ResponseWriter. A Router sends each request to a handler by method and path, and http_serve runs the server. To serve a directory of files without writing any code, run qiq serve.

    FunctionDescription
    http_serveRun an HTTP server
    http_file_serverA handler that serves files from a directory
    http_strip_prefixRemove a prefix from the path before calling a handler
    http_logLog each request to stderr
    http_content_typeThe Content-Type for a file name

    Program

    The running program: its command-line arguments, its exit status, and its environment variables.

    FunctionDescription
    argvThe command-line arguments
    exitEnd the program with an exit status
    getenvRead an environment variable

    Conversions

    qiq never converts between types implicitly: 1 + 1.5 and "n" + 1 are compile errors. These built-in functions convert explicitly. They are part of the compiler rather than declared in stdlib/, because each accepts several types, and like other built-ins they can't be redeclared. Each also accepts its own result type and returns the value unchanged.

    FunctionDescription
    to_intConvert a value to an int
    to_doubleConvert a value to a double
    to_byteConvert an int to a byte
    to_stringConvert a value to a string

    Output

    Writing to standard output. See also Printing in the language reference.

    FunctionDescription
    printWrite values to standard output

    The Response class

    The result of an HTTP request: status, headers, and body.

    The Request class

    A request received by the HTTP server: method, path, headers, and body.

    The ResponseWriter class

    Builds the HTTP server's response to a request.

    The Router class

    Sends each HTTP request to a handler by method and path.

    The Socket class

    TCP connections, optionally encrypted with TLS, for talking to network services.
