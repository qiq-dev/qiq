Classes and objects

Defining a class

A class has typed properties and methods. The constructor is named __construct. Create objects with new, use -> for properties and methods, and this for the current object.

```qiq class Person { private string name; private int age; function __construct(string name, int age) { this->name = name; this->age = age; } function describe(): string { return this->name + " (" + to_string(this->age) + ")"; } } Person ada = new Person("Ada", 36); print(ada->describe()); ``` ```output Ada (36) ```
  • Properties without a default (see below) start at zero, false, or null until assigned.
  • A constructor has no return type. A class without a constructor is created with new ClassName().
  • Objects are references: assigning or passing one shares it.
  • Printing an object prints its class name, unless the class has a __toString method (see below).
  • Reading a property of null, assigning one, or calling a method on it throws RuntimeException; see the nullsafe operator for a way to skip null.

Default values

A property can have a default, which every new object starts with. Defaults are set before the constructor runs, so the constructor can use or change them:

```qiq class Cart { public string currency = "EUR"; public int discount = 0; public string[] items = []; public map[string, int] quantities = {}; function add(string item): void { array_push(this->items, item); this->quantities[item] = (this->quantities[item] ?? 0) + 1; } } Cart mine = new Cart(); Cart yours = new Cart(); mine->add("tea"); mine->add("tea"); print(mine->currency, mine->items, mine->quantities, yours->items); ``` ```output EUR ["tea", "tea"] {"tea" => 2} [] ```

A default must be a constant: a literal, a class constant, null, or an array or map literal made of those. Set anything else, such as a value worked out from the constructor's arguments, in the constructor. Each object gets its own copy of a default array or map, so yours above has no items. Subclasses get their parents' defaults too.

Inheritance

A class can extend one parent class with extends; the parent must be declared first. A subclass inherits the parent's properties and methods, and can override methods with the same signature (and the same or wider visibility).

```qiq class Shape { protected string kind; function __construct(string kind) { this->kind = kind; } function describe(): string { return "a " + this->kind; } } class Square extends Shape { private int side; function __construct(int side) { parent::__construct("square"); this->side = side; } function describe(): string { return parent::describe() + " with side " + to_string(this->side); } } Square square = new Square(3); print(square->describe()); ``` ```output a square with side 3 ```
  • parent::__construct(...) calls the parent's constructor; it's only allowed inside a constructor. A subclass without its own constructor inherits its parent's.
  • parent::method(...) calls the parent's version of a method, even one the subclass overrides.
  • A subclass object can be used wherever the parent type is expected: Shape shape = new Square(3);.

A method call runs the version of the object's own class, as in PHP, even through a variable of a parent type. A call with omitted optional arguments uses the defaults of the method that runs. Private methods aren't overridden: a private method is always called in the class that declares it.

```qiq class Animal { function sound(): string { return "..."; } function speak(): string { return "It says " + this->sound(); } } class Dog extends Animal { function sound(): string { return "woof"; } } Animal pet = new Dog(); print(pet->speak()); pet = new Animal(); print(pet->speak()); ``` ```output It says woof It says ... ```

Calls to methods that no subclass overrides are compiled as direct calls; the others look up the object's class in a table, so overriding costs one extra load per call.

Constructor promotion

A constructor parameter written with a visibility (public, protected, or private), or with readonly, is also a property of that name and type, set from the argument before the constructor's body runs. It saves declaring each property and assigning it:

```qiq class Point { function __construct(public readonly double x, public readonly double y = 0.0) {} function moved(double dx): Point { return new Point(this->x + dx, this->y); } } class User { function __construct(public string name, private string email, bool admin = false) { print("new user", this->name, admin); } } Point p = new Point(1.5, 2.0)->moved(1.0); User ada = new User("Ada", "ada@example.com"); print(p->x, p->y, ada->name); ``` ```output new user Ada 0 2.5 2 Ada ```

Promoted and ordinary parameters can be mixed, as admin shows, and promoted ones can have defaults. Only a constructor's parameters can be promoted.

Readonly properties

A readonly property can only be set by the constructor of the class that declares it, through this; anywhere else, including in a subclass or another method, assigning it is a compile error. This makes value objects that can't change once created, such as Point above, where p->x = 0.0; doesn't compile.

  • A readonly property can't have a default (set it in the constructor instead), and can't be static.
  • Readonly fixes which array, map, or object the property holds, not what's inside it: array_push(bag->items, "b") still works on a readonly string[] items, as it does for objects in PHP's readonly properties.

Constants

const declares a value fixed when the program is compiled, read as ClassName::NAME, or self::NAME inside the class. The type comes from the value, or can be given: const int LIMIT = 10;. Constants can be int, double, bool, byte, string, or char, and their value is a literal or another constant.

```qiq class Http { const OK = 200; const int NOT_FOUND = 404; const string AGENT = "qiq"; const DEFAULT_STATUS = Http::OK; private const SECRET = "s3cret"; public int status = Http::DEFAULT_STATUS; function hint(): string { return self::AGENT + "/" + substr(self::SECRET, 0, 2); } } class Api extends Http {} Http response = new Http(); print(Http::OK, Http::NOT_FOUND, Api::AGENT, response->status, response->hint()); ``` ```output 200 404 qiq 200 qiq/s3 ```
  • Constants are public unless declared private (only the class's own code can read them) or protected (its subclasses too).
  • Subclasses, and classes implementing an interface that declares constants, read them through their own name: Api::AGENT. A subclass can't declare a constant its parent already has, so self:: and static:: always mean the same value.
  • Assigning to a constant is a compile error, and so are arrays and maps as constants, since arrays and maps can be changed in place. For a fixed list, use a static property or a function that returns it.

Checking an object's class: instanceof

value instanceof ClassName is true when value is an object of that class, of a subclass, or (for an interface name) of a class implementing it, and false otherwise, including for null. In an if condition, a name after the class binds the object as that class for the if branch, so its own properties and methods can be used:

```qiq interface Shape { function area(): double; } class Circle implements Shape { public double radius; function __construct(double radius) { this->radius = radius; } function area(): double { return 3.14159 * this->radius * this->radius; } } class Square implements Shape { public double side; function __construct(double side) { this->side = side; } function area(): double { return this->side * this->side; } } function describe(Shape shape): string { if (shape instanceof Circle circle) { return "a circle of radius " + to_string(circle->radius); } else if (shape instanceof Square square && square->side > 2.0) { return "a big square"; } else { return "a small shape"; } } Shape[] shapes = [new Circle(1.5), new Square(3.0), new Square(1.0)]; foreach (shapes as shape) { print(describe(shape), shape instanceof Square); } ``` ```output a circle of radius 1.5 0 a big square 1 a small shape 1 ```
  • The name is a new variable, visible only in the if branch, and in conditions after the check that are joined to it by &&, as with square->side above. A condition can bind several names: if (a instanceof Circle c && b instanceof Square s).
  • A name can only be given in an if condition, on its own or joined by &&. Elsewhere (in a while, after !, with ||), use instanceof without a name.
  • The value checked is evaluated once, even when it's a call.
  • Checking for a class that can't be related, such as circle instanceof Square when neither class extends the other, is a compile error.
Note: In PHP, $shape instanceof Circle is enough to use $shape->radius afterwards, since PHP checks types when the code runs. qiq checks them when it compiles, so the name says which variable has the narrower type, as in Java and C#.

Comparing objects

== and != on objects test whether two values are the same object, like PHP's ===. Two objects with equal properties are still different objects. The two sides must be related: of the same class, a class and its subclass, or an interface and a class that implements it.

```qiq class Node { public int value; public Node next; function __construct(int value) { this->value = value; } } Node first = new Node(1); Node copy = new Node(1); Node same = first; first->next = first; print(first == same, first == copy, first->next == first, copy->next == null); ``` ```output 1 0 1 1 ```

The nullsafe operator ?->

object?->property and object?->method() give null when object is null, instead of throwing, and skip the rest of the chain: in user?->address->city, nothing after ?-> runs when user is null. It's PHP's ?->.

```qiq class Address { public string city; public int floor; function __construct(string city, int floor) { this->city = city; this->floor = floor; } } class User { public string name; public Address address; function __construct(string name, Address address = null) { this->name = name; this->address = address; } function greet(): void { print("hello,", this->name); } } User ada = new User("Ada", new Address("London", 3)); User bob = new User("Bob"); User nobody = null; print(ada?->address?->city, bob?->address?->city ?? "no address"); print(ada?->address?->floor ?? 0, nobody?->address?->floor ?? 0); ada?->greet(); nobody?->greet(); ``` ```output London no address 3 0 hello, Ada ```
  • A number or bool can't be null in qiq, so ?-> to one needs a default with ??: user?->age ?? 0. With ??, the default is used when any ?-> in the chain meets null, or (for a string, array, map, or object) when the result is null.
  • object?->method(); on its own skips the call when object is null.
  • You can't assign through ?->: user?->name = "x"; is a compile error.

Converting objects to strings: __toString

A class with a public function __toString(): string method decides how its objects are written as text. print, to_string, + with a string or char, and sprintf's %s call it:

```qiq class Money { function __construct(public int cents) {} function __toString(): string { return sprintf("€%d.%02d", this->cents / 100, this->cents % 100); } } Money price = new Money(1250); print(price); print("total: " + price, to_string(price), sprintf("[%s]", price)); ``` ```output €12.50 total: €12.50 €12.50 [€12.50] ```
  • A subclass can override __toString, and an interface can declare it, so a variable of the interface's type converts with the object's own method.
  • print writes a null object as null; +, to_string, and sprintf throw RuntimeException for one, as they do for a null string.
  • Objects inside arrays and maps still print as their class name: print([price]) shows [Money].

Abstract classes

An abstract class can't be instantiated, and may declare abstract methods, which have no body and must be implemented by concrete subclasses. Calls to abstract methods run the object's own implementation, which is the template-method pattern:

```qiq abstract class Report { function render(): string { return "[" + this->title() + "]"; } abstract protected function title(): string; } class SalesReport extends Report { protected function title(): string { return "sales"; } } Report report = new SalesReport(); print(report->render()); ``` ```output [sales] ```

Final classes and methods

A final class can be instantiated but not extended, and a final method can't be overridden anywhere below the class that declares it. final can't be combined with abstract, used on a private method, or used in an interface.

```qiq final class Money { private int cents; function __construct(int cents) { this->cents = cents; } final function cents(): int { return this->cents; } } print(new Money(1250)->cents()); ``` ```output 1250 ```

Declaring class Euro extends Money {} would be the error class 'Euro' cannot extend final class 'Money'.
