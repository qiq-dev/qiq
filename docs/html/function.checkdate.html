    checkdate

    checkdate — Check whether a date exists

    Description

    checkdate(int month, int day, int year): bool

    Import it with import checkdate from "std/time";

    Checks that the date exists in the Gregorian calendar, taking leap years into account.

    Parameters

    month
    The month, 1 to 12.
    day
    The day of the month.
    year
    The year, 1 to 32767.

    Return values

    true if the date is valid.

    Examples

    Example #1 Leap years

    import checkdate from "std/time";

print(checkdate(2, 29, 2028), checkdate(2, 29, 2026), checkdate(2, 29, 2100), checkdate(4, 31, 2026));
    Output
    1 0 0 0
