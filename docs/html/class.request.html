    The Request class

    A request received by the HTTP server, passed to every handler, like Go's *http.Request.

    Import it with import Request from "std/http/server";

    Class synopsis

    class Request {
        public string method;
        public string path;
        public string rawPath;
        public string rawQuery;
        public string protocol;
        public string scheme;
        public map[string, string] headers;
        public byte[] bytes;
        public string remoteAddress;
        public map[string, string] params;
        function text(): string
        function header(string name): string
        function query(string name): string
        function form(string name): string
        function pathValue(string name): string
    }
    MemberDescription
    methodThe method in upper case: GET, POST, ...
    pathThe URL path, percent-decoded: /files/a b.txt
    rawPathThe path as the client sent it: /files/a%20b.txt
    rawQueryWhat follows ? in the URL, or an empty string
    protocolHTTP/1.1 or HTTP/1.0
    schemehttp, or https when a trusted proxy reports that the client used HTTPS (see trustProxy in http_serve)
    headersThe request headers, with lowercase names; a header sent more than once has its values joined with ,
    bytesThe body, empty when there is none
    remoteAddressThe client's address and port, such as 127.0.0.1:51234 or [::1]:51234; unix on a Unix socket. With trustProxy, the client address the proxy forwarded, such as 203.0.113.9
    paramsThe values of the wildcards in the Router pattern that matched
    text()The body as a string; throws InvalidUtf8Exception if it isn't UTF-8
    header(name)One header, by name in any case, or null
    query(name)A field of the query string (?page=2), decoded, or null; the first one if it's repeated
    form(name)A field of a form posted as application/x-www-form-urlencoded, or else of the query string, or null
    pathValue(name)A wildcard's value, such as id in /items/{id}, or null

    For a JSON body, decode the text into the type you expect: Item item = json_decode(r->text());.

    Example

    import Request, ResponseWriter from "std/http/server";

router->handle("POST /login", function(Request r, ResponseWriter w): void {
    string user = r->form("user");
    if (user == null) {
        w->error(400, "missing user");
        return;
    }
    w->write("Welcome, " + user + " (from " + r->remoteAddress + ")\n");
});
