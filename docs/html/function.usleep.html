    usleep

    usleep — Pause for microseconds

    Description

    usleep(int microseconds): void

    Import it with import usleep from "std/time";

    Pauses the program for microseconds microseconds.

    Parameters

    microseconds
    How long to pause; one second is 1000000.

    Return values

    Nothing.

    Errors/Exceptions

    • InvalidArgumentException if microseconds is negative.

    Examples

    Example #1 A short pause

    import hrtime, usleep from "std/time";

int start = hrtime();
usleep(50000);
print((hrtime() - start) / 1000000 >= 50);
    Output
    1
