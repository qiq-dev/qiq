Maps

A map stores values by key, written map[keyType, valueType]. It's the qiq counterpart of a PHP associative array.

```qiq map[string, int] ages = {"ada" => 36, "lin" => 29}; ages["grace"] = 85; // add an entry ages["ada"] = 37; // update one print(ages["ada"], ages["grace"]); int total = 0; foreach (ages as name => age) { total = total + age; } print(total, len(ages)); ``` ```output 37 85 151 3 ```

Keys and values

  • Keys can be int, double, bool, string, or char. String and char keys compare by content; for doubles, -0.0 and 0.0 are the same key, and NaN is rejected.
  • Values can be any type, including arrays and other maps: map[string, int[]], map[string, map[string, int]].
  • Reading a key that isn't in the map throws KeyNotFoundException.
  • len(map) is the number of entries.

Creating maps

A map literal is written {key => value, ...}. Its types come from its entries, and an empty {} takes its type from where it's used. A map declared without a value starts empty.

```qiq map[string, int[]] groups = {"small" => [1, 2], "none" => []}; groups["big"] = [7, 8, 9]; print(groups["small"], groups["none"], groups["big"]); map[int, string] names; names[1] = "one"; print(names); ``` ```output [1, 2] [] [7, 8, 9] {1 => "one"} ```

Maps are references

Like arrays, maps are shared when assigned or passed, so a function can fill in a map it's given. Map variables can be reassigned, for example to {} to start over. Comparing two maps with == compares their keys and values, in any order, not whether they're the same map; see Operators.

Order

Maps keep their entries in the order the keys were first added, as PHP arrays and Python dicts do. foreach, print, map_keys, and json_encode all follow that order. Updating a key's value keeps its place; removing a key and adding it again moves it to the end.

Checking, reading, and removing keys

```qiq map[string, int] stock = {"apples" => 3, "pears" => 0, "plums" => 12}; if (map_key_exists("pears", stock)) { print("pears are listed"); } int kiwis = stock["kiwis"] ?? 0; // a default instead of KeyNotFoundException unset(stock["pears"]); // no error if the key isn't there print(stock, kiwis); print(map_keys(stock), map_values(stock), in_map(12, stock)); ``` ```output pears are listed {"apples" => 3, "plums" => 12} 0 ["apples", "plums"] [3, 12] 1 ```
  • map_key_exists(key, map) tests for a key, and in_map(value, map) for a value.
  • map[key] ?? default reads a key, or gives default when the key is missing (or its value is null); see Operators.
  • unset(map[key]) removes an entry.
  • map_keys and map_values return the keys and values as arrays, in order.

Changing a map during foreach

Inside a foreach over a map, you can change values and remove entries, including ones the loop hasn't reached yet (they're skipped). Adding a new key to the same map throws RuntimeException, as in Python; collect the new entries in another map and add them after the loop.

```qiq map[string, int] scores = {"ada" => 90, "lin" => 40, "bob" => 75}; foreach (scores as name => score) { if (score < 50) { unset(scores[name]); } } print(scores); ``` ```output {"ada" => 90, "bob" => 75} ```
