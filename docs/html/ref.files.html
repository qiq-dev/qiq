    Files

    Functions for reading and writing files and directories. Paths are relative to the directory the program runs in, not to the source file. Failures throw exceptions; see Exception classes.

    Text functions such as file_get_contents require UTF-8 content, because every qiq string is UTF-8. To read or write anything else, such as images or text in another encoding, use file_get_bytes and file_put_bytes.

    import file_get_contents from "std/file";

try {
    string config = file_get_contents("config.txt");
    print(config);
} catch (FileNotFoundException e) {
    print("no config file, using defaults");
}
    Output
    no config file, using defaults
