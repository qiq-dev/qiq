    array_pop

    array_pop — Remove and return the last element

    Description

    array_pop(T[] array): T

    Removes the last element and returns it.

    Parameters

    array
    The array to change.

    Return values

    The element that was last.

    Errors/Exceptions

    • OutOfRangeException if the array is empty, and RuntimeException if it's null.

    Examples

    Example #1 A stack

    int[] stack = [1, 2];
array_push(stack, 3);
print(array_pop(stack), array_pop(stack), stack);
    Output
    3 2 [1]

    Notes

    Note: PHP's array_pop returns null for an empty array; qiq throws, as Python's pop does. Check len(array) > 0 first.
