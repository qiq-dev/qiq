    http_file_server

    http_file_server — A handler that serves files from a directory

    Description

    http_file_server(string directory): function(Request, ResponseWriter): void

    Import it with import http_file_server from "std/http/server";

    Returns a handler that serves the file at the request's path inside directory, with a Content-Type from its extension (see http_content_type). For a directory, it serves its index.html, or a listing of its files; a directory path without a trailing / is redirected to one. Only GET and HEAD are allowed (405 otherwise), and a path containing a .. segment gets 404, so files outside the directory can't be reached. Files are read whole into memory.

    Parameters

    directory
    The directory to serve.

    Return values

    The handler.

    Examples

    Example #1 A static site

    import http_file_server, http_serve from "std/http/server";

http_serve(":8080", http_file_server("public"));

    Example #2 Files under a prefix, next to other routes

    import http_file_server, http_serve, http_strip_prefix, Request, ResponseWriter, Router from "std/http/server";

Router router = new Router();
router->handle("/assets/", http_strip_prefix("/assets", http_file_server("assets")));
router->handle("GET /{$}", fn(Request r, ResponseWriter w) => w->write("home"));
http_serve(":8080", router->handler());
