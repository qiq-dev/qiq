    HTTP server

    An HTTP server in the style of Go's net/http. A handler is any function(Request, ResponseWriter): void, usually an anonymous function: it reads the Request and writes the response with the ResponseWriter. A Router sends each request to a handler by method and path, and http_serve runs the server. To serve a directory of files without writing any code, run qiq serve.

    Example

    import http_file_server, http_log, http_serve, http_strip_prefix, Request, ResponseWriter, Router from "std/http/server";

class Item {
    public string name;
    public int price;
}

Router router = new Router();
router->handle("GET /{$}", fn(Request r, ResponseWriter w) => w->write("Welcome!\n"));

router->handle("GET /hello/{name}", function(Request r, ResponseWriter w): void {
    w->write("Hello, " + r->pathValue("name") + "!\n");
});

router->handle("POST /items", function(Request r, ResponseWriter w): void {
    Item item = json_decode(r->text());
    w->status(201);
    w->header("Content-Type", "application/json");
    w->write(json_encode(item));
});

router->handle("/static/", http_strip_prefix("/static", http_file_server("public")));

http_serve(":8080", http_log(router->handler()));
    $ qiq run app.qiq
$ curl localhost:8080/hello/Ada
Hello, Ada!

    How the server works

    • Pre-forked workers. http_serve opens the listening socket, then forks worker processes (one per CPU by default) that each accept and serve one connection at a time, like Apache's prefork or PHP-FPM. The first process supervises them and starts a new worker if one exits or crashes, so a handler that crashes takes down one worker, never the server.
    • No shared memory between requests in different workers. Each worker is a separate process with its own copy of the program's variables, so a counter incremented by a handler counts per worker. Keep shared state in a file or a database.
    • Stopping. Ctrl-C (SIGINT) or SIGTERM stops the server gracefully: workers finish the request in progress and exit, and http_serve returns in the first process.
    • Errors. An exception thrown by a handler becomes a 500 Internal Server Error response, logged to stderr as qiq: 500 GET /path: message; the worker carries on.
    • Connections. HTTP/1.1 with keep-alive (and HTTP/1.0). A worker closes an idle connection after 5 seconds, or sooner when another client is waiting for a worker. Request bodies can be sent with Content-Length or chunked, up to 64 MB; Expect: 100-continue is answered.
    • Responses are collected in memory and sent with a Content-Length when the handler returns, with a Date header and, unless the handler sets one, Content-Type: text/plain; charset=utf-8. Responses to HEAD requests have no body.
    • Not supported yet: HTTPS (put a proxy such as Caddy or nginx in front), streaming responses, WebSockets, HTTP/2, and compression.

    Behind nginx

    In production, put the server behind nginx (or Caddy), as Go and Node apps are deployed: the proxy handles HTTPS, HTTP/2, compression, and static files, and it buffers slow clients, so a worker is busy only while your code runs. The program needs no special mode: listen where only the proxy can connect, and set trustProxy so requests show the visitor's address rather than the proxy's.

    import http_log, http_serve from "std/http/server";

http_serve("unix:/run/app/app.sock", http_log(router->handler()), trustProxy: true);
// or: http_serve("127.0.0.1:8080", http_log(router->handler()), trustProxy: true);
    server {
    listen 443 ssl;
    server_name example.com;

    location /static/ { root /srv/app; }    # files served by nginx itself

    location / {
        proxy_pass http://unix:/run/app/app.sock;    # or http://127.0.0.1:8080
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
    • Any user can connect to a Unix socket file, as to a port on 127.0.0.1; to restrict it, put it in a directory only nginx and the server can enter. The server replaces a socket file left by a crash, refuses to start if another server is listening on it, and removes it when it stops.
    • With trustProxy, r->remoteAddress is the client's IP address without a port, and r->scheme is https for visitors who used HTTPS, for building absolute URLs. Relative redirects such as w->redirect("/login") need neither.
    • Leave nginx's upstream keepalive off (the default): each idle connection nginx kept open would occupy a worker.
    • Run the program as a service, for example with systemd and Restart=always. systemd stops it with SIGTERM, which lets requests in progress finish.

    qiq serve

    qiq serve serves a directory with http_file_server, logging each request, like php -S or python -m http.server:

    $ qiq serve public --port 8080
Serving public at http://127.0.0.1:8080/ (press Ctrl-C to stop)
[Fri Nov 20 10:15:02 2026] 127.0.0.1:51234 [200]: GET / (0.2 ms)

    The directory defaults to the current one, --port to 8000, and --host to 127.0.0.1, which only this machine can reach; --host 0.0.0.0 listens on every network interface. --workers sets the number of worker processes.
