    urlencode

    urlencode — Percent-encode text for a query string

    Description

    urlencode(string text): string

    Import it with import urlencode from "std/http";

    Encodes the text's UTF-8 bytes as %XX, except letters, digits, and -_., and writes spaces as +, as PHP's urlencode does. Use it for query strings and form bodies; for path segments, use rawurlencode.

    Parameters

    text
    The text to encode.

    Return values

    The encoded text.

    Examples

    Example #1 Encoding a query value

    import urlencode from "std/http";

print(urlencode("fish & chips/é"));
    Output
    fish+%26+chips%2F%C3%A9

    rawurlencode, urldecode, http_build_query
