    to_double

    to_double — Convert a value to a double

    Description

    to_double(int|byte|string value): double

    Converts value to a double. A string must be a whole number such as "2.5", "-3", or "1e5", with no leading spaces.

    Parameters

    value
    The value to convert.

    Return values

    The converted value. Ints beyond 253 are rounded to the nearest double.

    Errors/Exceptions

    • InvalidArgumentException if a string isn't a number.

    Examples

    Example #1 Mixing ints and doubles

    int count = 7;
print(to_double(count) / 2.0);
print(to_double("2.5") * 2.0);
    Output
    3.5
5
