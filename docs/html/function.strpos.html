    strpos

    strpos — Find the position of the first occurrence of a substring

    Description

    strpos(string haystack, string needle, int offset = 0): int

    Returns the character position of the first occurrence of needle in haystack, at or after offset.

    Parameters

    haystack
    The string to search in.
    needle
    The string to search for.
    offset
    The character position to start searching from. A negative offset counts from the end.

    Return values

    The character position, counting from the start of haystack (not from offset), or -1 if needle isn't found. An empty needle is found at offset.

    Errors/Exceptions

    • InvalidArgumentException if offset is outside the string.
    • RuntimeException if a string argument is null (for example an unset element of a new string[n] array).

    Examples

    Example #1 Searching with and without an offset

    print(strpos("héllo wörld", "wörld"));
print(strpos("ab-ab", "ab", 1));
if (strpos("hello", "z") == -1) {
    print("not found");
}
    Output
    6
3
not found

    Notes

    Note: Unlike PHP, which returns false, qiq returns -1 when nothing is found. To only test for a substring, use str_contains.
