Anonymous functions

Functions are values: you can store them in variables, properties, arrays, and maps, pass them to other functions, and return them. An anonymous function (a closure) is written like a named function without the name, and can use the variables around it.

```qiq function(int, int): int add = function(int a, int b): int { return a + b; }; print(add(2, 3)); // The short form for a single expression; its return type is inferred. twice = fn(int x) => x * 2; print(twice(21)); ``` ```output 5 42 ```

Function types

The type of a function value is written function(parameter types): return type, such as function(string): bool or function(): void. It's used like any other type, for variables, parameters, return values, properties, and map values. For an array of functions, put the function type in parentheses: (function(): int)[], since function(): int[] is a function that returns an array.

```qiq function applyAll(int[] values, function(int): int f): int[] { int[] results; foreach (values as value) { array_push(results, f(value)); } return results; } print(applyAll([1, 2, 3], fn(int v) => v * v)); map[string, function(int, int): int] operations = { "add" => fn(int a, int b) => a + b, "multiply" => fn(int a, int b) => a * b }; print(operations["multiply"](6, 7)); ``` ```output [1, 4, 9] 42 ```
  • A function value must be called with exactly its parameters: no defaults or named arguments.
  • Function values can be null; calling a null one throws RuntimeException. Compare with == null.
  • A named function can be used as a value where its type is expected: applyAll(values, square). Built-in functions such as len can't; wrap them: fn(string s) => len(s).

Capturing variables

An anonymous function can use any variable in scope where it's written. It shares the variable with the code around it, as in Go, JavaScript, and Python: changes made inside the function are seen outside, and the other way round.

```qiq int count = 0; function(): void increment = function(): void { count++; }; increment(); increment(); print(count); ``` ```output 2 ```

A captured variable lives as long as any function that uses it, so a function can return a closure that keeps its own state:

```qiq function makeCounter(int start): function(): int { int current = start; return function(): int { current = current + 1; return current; }; } function(): int a = makeCounter(10); function(): int b = makeCounter(100); print(a(), a(), b(), a()); ``` ```output 11 12 101 13 ```
  • Each pass through a loop has its own loop variable, so closures made in a loop each see their own value.
  • Inside a method, a closure can use this and the class's private members.
  • foreach and catch variables stay read-only inside closures.
  • A function can call itself through a variable it captures, for recursion: declare the variable first (function(int): int fib = null;), then assign the function to it.
```qiq (function(): string)[] greeters = []; foreach (["Ada", "Lin"] as name) { array_push(greeters, fn() => "hello " + name); } foreach (greeters as greet) { print(greet()); } function(int): int factorial = null; factorial = function(int n): int { if (n <= 1) { return 1; } return n * factorial(n - 1); }; print(factorial(10)); ``` ```output hello Ada hello Lin 3628800 ```

Arrow functions

fn(parameters) => expression is a function whose body is one expression, like PHP's arrow functions. Its return type is the expression's type, or the expected type when it's passed or assigned where a function type is known. An expression that is a call to a void function makes a void function. print is a statement, so it can't be an arrow function's body.

Calling function values

Call a function value like a function: f(x) for a variable, object->callback(x) for a property holding one (when the class has no method of that name), and expression(x) for anything else, such as makeAdder(2)(3) or (fn(int x) => x + 1)(41).

Memory

A function value is reference counted like an object. Its captured variables stay alive while any function that uses them does. Closures often form reference cycles (an object holding a closure that uses this, or a recursive closure), and the cycle collector frees those.
