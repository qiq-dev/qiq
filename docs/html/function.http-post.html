    http_post

    http_post — Send a POST request

    Description

    http_post(string url, string body = "", map[string, string] headers = null, int timeout = 30): Response

    Import it with import http_post from "std/http";

    Same as http_request("POST", url, body, headers, timeout).

    Parameters

    url
    An http:// or https:// URL.
    body
    The request body.
    headers
    Headers to send.
    timeout
    Seconds to wait for each connect, read, and write.

    Return values

    The response.

    Errors/Exceptions

    • As for http_request.

    Examples

    Example #1 Sending JSON

    import http_post, Response from "std/http";

Response r = http_post("https://api.example.com/items",
                       json_encode({"name" => "Lamp", "price" => 25}),
                       {"Content-Type" => "application/json"});
r->raiseForStatus();

    Example #2 Sending a form

    import http_build_query, http_post, Response from "std/http";

Response r = http_post("https://example.com/login",
                       http_build_query({"user" => "ada", "password" => secret}),
                       {"Content-Type" => "application/x-www-form-urlencoded"});
